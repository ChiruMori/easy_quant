# 后台任务分页与指数维护

后台任务按计划时间倒序展示，同一时刻按 ID 倒序稳定排序；服务端分页默认每页 20 条，最多 100 条，返回总数与实际页码，越界定位末页。界面支持翻页与跳页，轮询保留页码，失败可重试，360px 不溢出。

指数页初始不勾选任何指数，空选择不能提交。新增“主要指数日线同步”任务，使用已启用日线来源和固定不复权口径，默认同步七个主要指数，按各自覆盖补齐至最近已发布交易日；无数据时从十年前年初开始，可配置 start_day/end_day。沿用采集失败、部分完成和安全重试语义。

迁移为已有及新安装创建一个默认停用的指数计划（工作日 22:00），管理员可立即执行或启用；不覆盖已有指数计划。通达信任务明确只更新股票。指定数据集同步与盘后综合同步并非完全重复，不删除业务处理器或用户计划；改名并解释其范围。
