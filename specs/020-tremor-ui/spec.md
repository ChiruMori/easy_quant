# Tremor 风格工作台

**状态**：已实现并通过离线验证

## 目标与边界

用户从十种风格中选择第 2 种 Tremor 数据分析看板。统一浅灰背景、白色卡片、蓝色强调、指标层级、表格和图表，保留现有业务流程与权限。复用 React、shadcn/ui、Tailwind 与现有 API，不引入 Tremor 依赖、第三方运行请求或示例资金数据。

## 要求与验收

- 应用侧栏分为研究与管理，当前路由只有一个选中项；详情页和窄屏导航可以识别当前位置，普通用户不显示管理员入口。
- 概览从现有策略、回测、实盘列表生成真实统计与记录入口。加载、空数据和失败分别呈现，不将失败显示为 0，也不跨策略合并收益。
- 回测列表展示真实运行统计；详情以指标卡片和带轴单位的权益图呈现已有结果，保留运行反馈、交易、假设和追溯身份。收益指标缺失显示破折号。
- 策略、实盘和管理页面共享页头、卡片、表格、按钮与语义色；盈亏保留红涨绿跌，与蓝色主操作和任务状态区分。
- 360px 窄屏与桌面均可访问主要操作；宽表格在容器内滚动；键盘焦点、表单标签、侧栏折叠可用。
- 不修改日线、人工确认操作、邀请制与不可变策略版本等业务边界。
