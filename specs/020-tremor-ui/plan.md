# 实施计划

## 宪章检查

本次仅修改前端展示与现有只读列表的组合，不新增后端 API、数据模型、外键、服务、交易执行或注册能力。概览只统计当前账户有权读取的列表，不缓存跨账户数据，不生成假收益。自动化验证使用已有内存服务与网络拦截 fixture，不访问第三方服务或真实存储。

## 方案

1. 将全局语义 token 设为 Tremor 风格，调整共用 Card、Table、Sidebar 等组件；统一页头和指标卡片。
2. 为侧栏显式设置选中状态并按研究、管理分组，补齐详情页标题；布局容纳窄屏及长标识。
3. 概览复用现有 React Query key 与 API，展示策略数、回测状态、实盘数量和回测入口，正确处理加载、错误与空态。
4. 回测列表、详情与核心研究页面应用新布局；权益图只消费真实 periods，增加蓝色曲线、网格、中文工具提示和单位。
5. 同步当前使用说明，补离线统计/错误回归和 Playwright 导航、窄屏、主业务回归；运行格式化、静态检查、pnpm check 和 pre-commit。
