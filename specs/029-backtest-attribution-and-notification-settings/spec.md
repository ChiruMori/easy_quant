# 回测命名、股票收益归因与通知管理

创建回测可填写最多 160 字的名称，去除首尾空白；未填写时按策略名称、版本与起止日期生成可读名称，旧记录保留编号回退。列表、详情和比较选择器优先显示名称，名称不参与可比性判定、不改变运行标识。

已完成回测新增股票收益明细，覆盖期末持有和已清仓股票。使用 Decimal 移动平均成本，买入费用计入成本，卖出费用扣减已实现收益，滑点已经反映在成交价中，不重复扣减。总收益=已实现收益+期末浮动收益，按总收益降序、代码稳定次序分页。新回测保存执行时的期末估值和明细；旧回测使用原始成交与冻结快照重建，不读取当前行情或改写历史，缺少期末估值明确标记未知并排在末尾。跨用户不可读取。

策略草稿编辑页提供回测按钮，先保存当前名称、说明和源码，再跳转该版本的回测创建页；保存失败不跳转并保留编辑内容；新策略同样支持且不重复创建。保存按钮采用主题色。实盘收益、收益率复用红涨绿跌语义；图表单位可见文字仅为 ￥ / %，保留完整可访问名称；临时比较用内含关闭按钮的标签。已结束的建议隐藏操作按钮，提交中的操作保持防重复和错误恢复。

通知管理改为已配置渠道分页表格，新增和编辑使用弹窗；停用渠道可编辑名称和目标。目标仍加密存储，默认脱敏，仅本人显式显示或编辑时按需读取明文，不进入列表、日志或审计。编辑允许显示/隐藏，失败保留输入，更新不隐式启用。最近投递独立分页并按最近时间稳定排序，只返回本人安全诊断字段。启用、测试、删除沿用原有权限及约束。窄屏表格局部滚动，不撑宽页面。

验收：命名校验与持久化；部分卖出、清仓重买、费用与总权益对账；旧快照及缺失数据；收益排序分页和权限；自动保存成功、失败与重复点击；图表标签及单位；已处理操作不可见；停用渠道编辑、显隐权限、不泄露明文；两张通知表分页及异步失败；360px/宽屏截图。

追加：正预期示例替换为参数化单标的网格，展示固定锚点、网格间距、初始权重和每格权重；不保存假定成交状态，依赖实际持仓与预留。修复 SQL 仓储创建后原对象版本指针未刷新导致创建响应 current_version_id 为 null；返回实际创建版本。指数盘后更新独立采用 15:00 收盘截止，覆盖当天，来源缺尾日继续按既有验证回退/报错。
