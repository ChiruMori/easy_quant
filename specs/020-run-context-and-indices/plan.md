# 实施计划

宪章检查：维持日线和建议跟踪边界，无自动交易；策略版本不可变，外部发送与采集继续走现有适配器。资金使用 Decimal；指数仍受 available_at 约束。复用 JSON 运行状态和既有行情表，不新增外键、服务或网络测试。

1. 增加启动请求校验、策略版本上下文与通知渠道选择、命名和主动测试。
2. 增加独立实盘表单、版本预览、跳转及实盘信息展示。
3. 增加指数命名空间、主要指数目录、日线源适配和交易边界，计算并呈现基准。
4. 增加离线回归，更新 docs，运行格式化、pnpm check、Playwright 和提交钩子，提交推送并创建 PR。

失败处理：缺少指数行情明确阻止回测并提供同步入口；通知测试失败只报告脱敏状态；禁用渠道不投递。现存回测不改写历史指标；旧实例读取时按原有字段回退显示。
