# 回测与实盘上下文、通知与指数

1. 回测详情预览运行所引用不可变版本的策略名称、说明和代码，并能跳到该版本编辑入口；不得误展示最新版本。
2. 开启实盘先展示配置表单，要求独立填写正数初始现金、实盘名称和至少一个本人启用的通知渠道，允许独立修改策略参数、初始持仓和盘后提醒。拒绝无效资金、越权渠道、Mock 结果；失败不创建实例或调度。
3. 实盘列表及详情展示名称、策略、启动资金、参数和选中渠道，并保留原回测链接。
4. 通知配置可命名、改名并主动发送一次测试通知，结果脱敏；实盘只投递给其选中渠道。旧实例维持历史全渠道行为。
5. 指数以 sh/sz 前缀隔离股票代码，预置主要指数，复用日线同步、覆盖和数据查询；不复权。000300 基准规范化为 sh000300。指数行情可供策略查询，但所有执行/建议入口禁止指数交易。
6. 选择基准后必须有完整真实区间行情，否则明确报错；成功回测显示基准名称、收益和归一到初始资金的曲线，不静默忽略缺失。

验收：离线 API 测试验证资金、参数、渠道与归属；fake 投递验证定向和测试反馈；固定日线验证指数与股票隔离、时间边界、基准曲线和交易禁止；前端与 Playwright 验证表单及版本跳转。

## PR11 合并后的增量要求

- 回测指标、权益及基准曲线统一采用 Tremor 语义 token，保留中文工具提示中的独立序列名称、坐标单位与图例；实盘、通知、指数页面使用共享页头和窄屏布局。
- 数据管理、通用拉取页提供明确的“指数数据”入口。专用页面直接展示主要指数目录、同步区间、记录数和缺数状态，即使未刷新股票清单也可使用。
- 允许选择一个或多个指数及起止日期创建后台日线同步任务；可全选主要指数。拒绝股票代码、空选择和倒序日期，不创建无效任务。沿用日线来源开关、任务进度、失败明细和重试流程；完成后刷新覆盖并可跳转 K 线。
- 管理员权限覆盖指数目录和同步 API。请求校验、任务流转和 360px 页面均有离线回归。
