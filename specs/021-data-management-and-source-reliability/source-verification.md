# 来源核验记录（2026-10-16）

手工只读访问公开行情接口，与离线自动化测试分开；未写入用户数据库。统一请求 2026-10-01 至 2026-10-15。

| 来源 | 实测 | 处理 |
| --- | --- | --- |
| 腾讯指数日线 | 修正适配器后，七个指数均返回 6 条有效日线，最新 2026-10-15 | 保留；直接按年请求指数接口，兼容可变字段数量 |
| AKShare / 新浪指数历史 | 使用受超时限制的 HTTP 客户端及 AKShare 的固定本地解码器，七个指数均返回 6 条有效日线，最新 2026-10-15 | 保留；避开原东方财富代码映射依赖 |
| 东方财富直连 | sh000001 的较长区间曾返回 247 条，最新 2026-10-15；后续批量请求和代理路径出现连接断开 | 保留；属于间歇性可用，空数据与连接失败均触发来源切换 |

七个指数为 sh000001、sh000016、sh000300、sh000852、sh000905、sz399001、sz399006。没有证据支持删除其中某个来源为“已停用或不维护”。AKShare 安装版本为 1.18.97，其新浪指数实现与官方指数文档仍存在并可用。

根因：原腾讯股票接口先探测上市年份，指数响应导致整数解析失败；原 AKShare 指数接口依赖东方财富代码映射，而该请求连接失败；东方财富的空响应被当成成功并缓存，提前终止来源切换，最终产生“成功 0 条”。修复后在缓存和来源成功之前校验日线内容及指数目标日期。

参考官方实现和文档：[指数接口](https://github.com/akfamily/akshare/blob/main/docs/data/index/index.md)、[新浪与腾讯指数适配](https://github.com/akfamily/akshare/blob/main/akshare/index/index_stock_zh.py)、[东方财富指数适配](https://github.com/akfamily/akshare/blob/main/akshare/index/index_zh_em.py)。公开接口后续可能波动，本记录仅说明上述时间的实测结果。
