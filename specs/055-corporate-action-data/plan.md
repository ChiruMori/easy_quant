# 实施计划

1. 纯领域事件模型、PIT 版本选择、覆盖检查及复权变换，独立于 pandas/SQL/HTTP。
2. 复用 market_records 存储不可变内容寻址事件、覆盖证明和候选，不新增外键，不重写价格大表。提供审计/导入 CLI；旧分红方案迁移保持 observed 可见时点，不猜测派息/上市日期。
3. 策略、因子研究入口统一应用复权视图；交易报价继续原价。快测与正式运行均拒绝未经核实的生产数据，测试用明确的内存覆盖 fixture。
4. 回测公司行为状态机及应收权益、停牌估值；实盘设置核对闸门并提供审计确认，保证不会自动执行交易。
5. 衔接盘后同步，更新当前文档，运行离线领域/接线/迁移测试及全量门禁，提交功能分支并创建 PR。

宪章检查：仍为日线决策辅助，无自动下单、分布式组件或注册扩展；研究 float64 与账本 Decimal 明确分离；经济信息按 available_at 过滤，完整性证明为操作元数据；领域不依赖外部边界；数据采集失败不产生覆盖证明；旧数据不猜测重写；测试仅 fake 和固定样本；新增存储使用已有无外键通用事件记录。

数据源实测：现库存量 provenance 全部为 none；官方 gbbq ZIP 已保存且含事件文件，但缺少完整可获知版本和权益到账日期。东方财富分红记录缺到账字段。二者只能补充核对，不能据此认证全部历史。源数据不满足时通过闸门阻止，标准事件导入提供补齐通道。
