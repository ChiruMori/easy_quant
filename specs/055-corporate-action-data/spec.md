# 公司行为、研究复权与账本一致性

保留不复权日线为成交事实；在独立、不可变的版本记录中保存公司行为及完整性证明，按决策时点生成研究视图。旧 qfq/unknown 数据不得反推原价或混入交易账本。迁移默认只读报告；没有公告时间、实施状态、到账日期的分红方案只能作为待核对候选。

公司行为按证券与除权日合并建模，支持现金分红、送股、转增、配股、拆股、合股，以及公告明确的特殊参考价。数量统一为每原股，现金人民币元；不能把增发、回购和流通股上市直接当成除权。事件保留来源、证据、可获知时间、采集时间和内容身份；修订追加版本。空事件集必须有明确的覆盖证明，不能把缺数据当成没有事件。

研究默认采用决策日锚定的等比前复权 OHLC，显式提供 raw/qfq/hfq 视图和原始成交价；成交量、成交额保留实际口径并给出独立的股数换算因子。未来事件不参与历史锚定；对已生效但当时尚不可获知的事件报错。前后复权的比例收益相同，但不宣称等于现金到账后再投资的真实收益。

回测使用原价成交。登记日收盘锁定权益，除权日确认应收现金与股份，派息日才增加可用现金，股份上市日才可卖。停牌期间保留最后估值并在事件日变换估值基准，不让缺当日行情抹掉资产。配股不隐含自动认购；缺少明确缴款/权益处置数据的持仓配股必须中止，不输出假收益。合股碎股等需要明确处置规则，不能静默舍入。

实盘不得凭行情源自动改写实际持仓；已持有标的发生公司行为时，在实际权益核对完成前阻止继续生成建议。确认记录须幂等、绑定事件版本和真实到账/股数，保留审计；旧待处理建议须失效，不能沿用除权前的触发价和数量。

同步任务保存可复用归档和候选，不将候选自动升级为可信事件。提供一次性迁移/审计和标准化事件导入工具，支持离线证据补齐，未核实覆盖保持阻断。可信范围通过工具和 API 可查询。

验收覆盖：六类事件及同日复合事件；PIT/修订/未来锚点；现金与股数单位；原价成交与研究连续性；登记日后卖出/除权日新买不错误获利；应收款不可花、未上市股份不可卖；幂等与失败恢复；无覆盖、qfq、缺日期、配股和碎股阻断；迁移不修改原始行情；快测/回测/实盘接线与输入身份。
