## 宪章检查

保持日线、受控用户、无自动下单及无分布式扩展；领域计算不依赖网络或数据库。原价与资金账本保持现有明确口径，研究采用 float64。源文件及转换版本进入输入身份；历史重建与严格 PIT 版本能力分开披露，不能把本次采集时间倒填为历史公告时间。未来除权事件不参与早期决策锚定，未知公司行为不混入无事件区间。测试使用固定离线 fixture；新存储不新增外键。

## 接入顺序及验收任务

- [x] T007 为价格调整与实际权益建立独立能力契约。价格事件只要求可靠的事件类型、生效日、调整数值及来源；派息日、股份上市日只限制确实依赖它们的权益操作。披露来源内校验与历史重建能力，不沿用“全部公告已认证”的标签。
- [x] T008 全市场整理已导入候选，无需重新逐股导入。先提供预览，分类列出转换成功、非价格记录、冲突、缺原价及不支持类型；明确每十股/每股、Float32 精度、同日复合事件、价格调整量与实际权益量的区别。核实类别 11/12 的比例和类别 15 的调整语义；不能套用类别 1 的四个字段。完整归档可作为供应商事件清单的依据，未知类型仍隔离受影响证券和区间。
- [x] T009 按“事件来源身份＋转换版本”幂等生成价格调整数据和供应商覆盖清单。重跑不重复生效，源修订保留旧版本并定位需要重建的区间；保留现有不复权日线。内容键不含转换必需字段时回读归档，不能猜测缺失值。
- [x] T010 统一图表、技术因子及策略历史的研究价格入口，优先前复权。K 线增加前复权/不复权切换；后复权能力存在且可验证时再展示。先调整日线后聚合周/月线，返回锚点与口径，切换请求不得串用缓存，失败不冒充不复权结果。指数保持原口径。
- [x] T011 将必要权益事件接入回测与实盘。普通分红、送转需要登记、到账/可卖日期时先查通达信其他公开数据；确实缺失再从其他公开来源补齐。实际派现金额与差异化除权调整量分开。配股缴款、合股碎股或无法判断的日期只阻止相关操作/运行，不将其余普通价格研究一概判为不可用；实盘仍以人工确认的实际操作与权益为准。
- [x] T012 打通每日自动下载、解码、转换和发布，而不止维护候选。失败可重试，覆盖不中途发布，源修订使受影响派生结果失效；按事件生效日与当时可知范围应用。管理员只处理有具体原因的异常，不执行每日下载/导入。禁止仅因无事件或接口空响应而解除质量检查。
- [x] T013 离线验收与有界真实样本验收：纯分红、送转、配股、拆合股、同日复合、差异化分红、修订、未知类型、停牌、重复导入和失败恢复；确认普通事件不产生机械假信号，实际账本不漏记或重复入账。真实验收只读/预览优先，写入不覆盖原价；核对全市场成功/失败统计，不要求跨平台逐点相等。页面验证桌面及窄屏，执行项目门禁并沿用 PR #32。
