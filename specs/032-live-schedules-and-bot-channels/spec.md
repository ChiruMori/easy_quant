# 实盘比较、专属调度与群机器人

- 已终止实盘允许临时添加股票、指数比较，区间为启动至终止，包含暂停期间；运行或暂停实例截至当前已发布数据，不改变冻结实盘收益。
- 实盘专属计划不出现在系统定时任务列表，系统接口不允许创建、修改或手动触发实盘计划；实例详情展示自己的计划，随暂停/恢复自动停启，终止后删除。worker 清理历史已终止、已删除实例的遗留计划，不再为暂停实例排队。
- 系统未启用计划可二次确认删除；已启用计划拒绝删除，保留后台执行历史与审计。
- 实盘分析后台任务和 worker 日志包含实例名称、编号和分析阶段，失败与跳过也能识别来源。
- 增加钉钉、飞书、企业微信群机器人 Webhook 渠道，钉钉/飞书支持可选签名密钥；沿用加密保存、显隐编辑、测试投递、按轮信号聚合和重试。HTTP 及业务响应均校验，日志/错误不包含地址、token 或密钥。

验收：冻结收益不受新行情改变而比较止于终止；暂停期间比较连续；计划隔离、权限、二次确认、启停及历史清理；三个机器人协议和签名、限流重试、错误脱敏均使用离线 fake/MockTransport。
