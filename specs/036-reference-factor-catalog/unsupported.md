# 未支持因子与所需改造

依据：[Tushare公开明细](https://tushare.pro/document/2?doc_id=486)，核对日期2026-10-25。公开明细202项，本轮实现85项，以下117项阻塞。摘要称272项，但未提供另外70项Alpha101的逐项公式，因此它们不计入202项实现分母。

这里记录未来改造，不代表已有能力。实现范围与当前口径见[当前说明](../../docs/对标因子.md)。

## 改造依赖

- F1：新增完整财务三表与分红平台数据能力，独立适配器、同步任务、单位归一和记录身份；保留公告、报告期、财务类型、合并范围及修订版本。无需修改K线或新增外键。
- F2：以决策时点选可见报告，再区分年度、累计、单季、TTM；季度流量从累计差分，TTM按已公开四季度组装，禁止提前使用后续修订。提供按交易日滞后查询，并为缺季、跨年、负分母及异常财务口径建离线fixture。财务截面排名复用本轮算子，但需要完整PIT输入，不能只加一个数学表达式。
- S1：独立管理A股股本与流通股本的生效日/可获知时间和公司行为，单位统一为股，不能用当期股本回填历史；明确成交量单位后完成逐日join和窗口测试。
- D1：修正或明确参考公式歧义，记录本平台最终口径并提供可核对样例。
