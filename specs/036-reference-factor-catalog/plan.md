# 实施计划

1. 逐项建立来源与状态清单，明确公开列表缺项及定义冲突。
2. 先去兼容并迁移平台模板；打通完整OHLCV/成交额运行快照及声明式长窗口预热，复用既有K线数据和同步。
3. 以 Decimal 序列算子和显式截面股票池实现量价、动量、反转、风险及可支持的规模计算；实现局部复用，不引入通用代码执行器或 eval。
4. 同步离线测试、用户文档、逐项阻塞报告；执行Ruff、pnpm check、受影响浏览器验收与提交钩子，推送当前功能PR。

宪章检查：纯计算不依赖数据库/网络/时钟，读取均经平台上下文；保持 available_at、输入口径与策略版本不可变；不新增存储、外键、服务或结果缓存。截面股票池与指数显式，缺失数据不能用当前财务/股本回填。不修改K线存储布局，不删除用户业务数据。未来财务改造仅写spec报告。
