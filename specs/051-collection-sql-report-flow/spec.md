# 证券写入修复与财报收支展示

修复MariaDB/PyMySQL证券批量upsert的1064错误，保留500条批次、停牌保护和缺失上市日期不覆盖语义。离线驱动回归必须覆盖最终发送SQL参数已完全绑定；不接触真实数据库，不执行迁移。

确认采集请求按开始时间相隔至少5秒，响应和本地处理耗时计入间隔；不足部分才等待，跨任务领取同样有效。

管理员补采报告期按当前股票、数据集、来源区分已有报告/当前指标缺失/未采集，仍允许重新拉取。加载或失败不能误标为未采集。

财务报表的“全部报告”按年份分组，每组并列一季报、中报、三季报、年报四根柱，展示原报告累计值或时点值，不求和、不相减推算单季度。未到期报告不产生数据，缺失仍为空，保留逐报告数值表；窄屏允许图表内部横向滚动。

主营按单报告期、单来源、单分类同时展示收入、成本与利润。完整非负且收支相符时使用桑基图；缺失、负值或不平衡时用三指标组合柱图，明确原因、保留原值和数值表，不推算或取绝对值伪造流量。验证桌面与360px及失败恢复。
