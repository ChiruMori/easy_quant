# 财务因子复核与 TA-Lib 策略支持

复核公开202项与现有财务规范字段。仅注册能够以合并人民币报表、明确累计/单季/年度/TTM口径计算的项目；报告版本先按决策时点过滤，不混合来源、报告期或币种，不以历史报告期代替可获知时间。截面显式股票池至少2只，任何成员缺失则明确失败。

TA-Lib 安装在 backend/.venv 并锁定依赖。策略允许 import talib 与受限 numpy 数组工具；导入验证和运行时同时设白名单，不提供任意模块或文件/网络接口。单次与流式运行一致，保留子进程超时。现有 Decimal 因子的递归种子与 TA-Lib 不等价时保持既有计算，复用内部公共算子。

验收：可手算财务值、TTM/单季、未来修订/乱序/缺期/不同来源/零分母、截面并列与完整性；TA-Lib 真实子进程运算、非法导入拒绝；更新当前支持清单及逐项阻塞原因与改造条件。无新存储、迁移或日线修改。
