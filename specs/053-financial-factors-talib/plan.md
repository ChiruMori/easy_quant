# 实施计划

1. 核对官方公开公式、当前字段、财报可见性与原有因子；记录可支持范围和定义/数据风险。
2. 实现纯 Decimal 财报期别组合及严格来源、币种、期别检查，注册元数据与运行依赖。
3. 安装 TA-Lib，提供受限模块门面及 AST/运行时导入白名单，验证单次和流式执行；复用既有 EMA 算子。
4. 维护 docs 当前清单、计算说明、策略用法与阻塞改造表；离线测试、完整 check、相关 Playwright 和提交钩子后创建 PR。

宪章检查：仍为低频研究，不涉及高频、下单、注册、分布式或模型训练。财务计算不依赖框架、数据库、网络、环境时间。缺失不补零；资金保持 Decimal，TA-Lib 技术指标明确使用 float64。仅安装已有后端进程内数值依赖，策略继续在受限子进程运行，无新增外键或数据库变更。
