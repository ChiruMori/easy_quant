# 自动采集与盘后恢复

日常采集由默认启用的盘后综合计划自动执行，包含八类财报基本面，管理员无需逐股票每日维护。应用启动补齐缺失计划；已有自定义时刻和明确停用配置保留。数据管理展示自动采集状态、下次执行时间及计划入口，手工范围拉取只作补采。

东方财富证券和估值清单须完整分页读取沪深京，以实际返回条数推进，验证总数稳定、代码唯一、页非空及安全上限。证券校验在缓存和来源成功判定前执行，截断或空数据自动重试切源，不能误标退市。

盘后编排隔离基础刷新失败，对现有已确认证券继续创建独立采集批次，明确保留部分失败和来源明细。数据采集失败延迟自动重试最多3次，成功批次幂等，耗尽仍如实显示失败，次日继续计划。无已知清单时不能伪造标的。

不改K线表或数据存储，不新建表或外键，不在真实库全市场采集。离线验证分页、切源、隔离、重试持久化、自动计划及宽窄屏入口。
