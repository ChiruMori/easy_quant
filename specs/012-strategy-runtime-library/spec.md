# 策略公共库与统一运行时

状态：已实现并完成离线验收。范围：日线决策辅助、单机 worker、人工成交；不接入自动交易。

## 功能要求

1. 快测、回测、实盘使用同一 context、因子计算和策略模板。价格、资金、数量、技术和统计结果使用 Decimal；JSON 边界使用十进制字符串。删除子进程中的重复因子算法。
2. context 提供有文档的股票池/行业、证券状态、基本面历史、报价、组合、比例信号和 KV 接口。买入比例以阶段开始可用现金为基数，卖出比例以标的实际持仓为基数；比例必须在 (0,1]，数量按交易单位向下取整，不隐式满仓或清仓。原数量信号继续可读。
3. KV 按运行隔离，跨阶段和跨交易日保留。模拟运行内存保存；实盘按实例持久保存，阶段成功时与建议原子提交；失败不保存，重试不得重复改变状态。策略不能直接改写实际账本。
4. 回测与快测均推进模拟组合，只有接受的模拟成交入账；实盘只生成建议，人工录入实际价格、数量、费用后更新权威组合。
5. 每个交易日仅运行一次盘中分析，使用系统统一配置的时间（默认 14:50，Asia/Shanghai）；重复任务幂等。盘前不请求数据源；可关闭盘后阶段及核对提醒，默认关闭。
6. 实盘盘中仅为策略请求的股票获取真实临时报价，受限子进程不得直接联网。模拟报价为当日 (open+close)/2；必须保存这是含当日收盘信息的模拟假设，不声称历史盘中报价精确可复现。日线和基本面因子仍遵守决策时点可见性。
7. 快测默认小窗口并推进一日模拟组合；可显式选择确定性 Mock 补历史，所有补值和使用状态可见，不能用于启动实盘。回测、实盘不补造数据。
8. 提供管理员可配置的盘后全量同步任务（例如每日 22:00），保存各数据集成功/失败并支持重试；盘前读取已同步数据。不可获知的财报不得用报告期代替公告时间。
9. 数据管理以最近已发布/可同步交易日判断过期，盘中仅缺当天日线不显示过期或更新按钮。同步已证实来源尚未发布时，隐藏同一目标的无效更新操作；新交易日可重新尝试。
10. 增加与因子目录一致的策略库文档页面，说明签名、参数、返回值、示例、运行时差异、状态和数据不足行为。
11. 本地参考材料仅用于阅读；不得进入产品、代码、测试、文档或示例。

## 验收场景

- 同一策略在三个运行时调用同一 MA5/MA30 得到一致 Decimal 结果；不足时明确失败/不可用，显式快测 Mock 另行标记。
- 10% 现金买入、50% 持仓卖出得到部分仓位，余额/费用不足不超支；模拟下一阶段看到成交，实盘未确认前不改变组合。
- KV 盘前写、盘中读、跨日读；实盘重启恢复；失败和重复任务不重复应用；用户及实例相互隔离。
- 止损、突破、加仓和无条件盘中信号可表达；非交易日不运行；同日盘中只执行一次。
- 实盘报价请求仅包含策略所需股票，无请求则不联网；回测和快测不调用真实报价接口。
- 盘中昨天日线为最新时不显示过期；来源尚未发布时重复按钮隐藏；盘后可配置任务同步真实数据。
- 文档页面可搜索接口并查看调用方式；全部测试使用 fake、内存仓储和固定样本。
