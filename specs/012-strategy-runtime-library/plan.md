# 实施计划

## 宪章检查

- 保留受控邀请、日线、单 worker、动态策略受限进程和人工交易账本。
- 共享 context 和因子通过只读快照与显式报价交换；领域内无网络、时钟和数据库依赖。
- 实盘 KV 复用已有 MariaDB 短事务，不新增服务；模拟状态按运行在内存隔离。
- 用户明确允许快测 Mock 及开收盘均值模拟报价：修订宪章为显式模拟例外，标记不可用于正式回测数据补造或实盘启动；保持基本面和历史日线时间边界。
- 记录数据身份、模拟报价口径、比例、KV 和阶段幂等；离线验证 Decimal、回滚、权限及数据不足。

## 设计

1. 共享 RuntimeContext 调用唯一 FactorRegistry。受限进程从受控安装包载入平台模块，Decimal 可在策略中直接使用；策略仍不可导入模块。
2. 报价采用父子进程请求协议：策略调用 quotes/current_price 时申请所需股票，宿主只在实盘盘中调用报价端口，模拟使用预置快照。限制请求和返回尺寸。
3. 比例辅助函数生成兼容 Signal 的数量及比例身份，记录建议中的比例和基数。触发方向显式选择，不再绑定买卖方向或空仓限制。
4. 单阶段执行返回 KV 候选；回测跨日保留，快测采用相同阶段领域引擎，实盘短事务校验阶段与状态版本后原子提交。
5. 系统配置统一盘中时间，创建 cron 任务并兼容已有间隔任务；实盘成功阶段键去重。增加盘后全量同步 handler 和管理入口。
6. 日线新鲜度使用发布截止时刻，来源未发布时记目标交易日及已观察最新日，覆盖接口据此抑制无效操作。
7. 添加公共库目录 API/页面及当前行为文档，更新 OpenAPI 与离线端到端测试。

## 风险

开收盘均值含收盘信息，只代表用户指定的模拟近似；历史行业/ST/财务缺少来源时返回明确缺失，不以当前值伪造历史。全市场盘后同步可能耗时，必须在任务结果中展示失败和已完成范围。已有策略数量协议保留，新增比例辅助工具优先使用。
