# 策略能力契约

本文记录平台的数据查询、信号和三阶段执行契约。当前公共接口与运行时约定以 specs/012-strategy-runtime-library 为准。

## 接入边界

参考策略需要拆成 `before_market`、`on_market`、`after_market` 三个钩子，不能直接依赖聚宽全局变量、查询 DSL、自动调度或下单函数。策略只产生 `buy`/`sell` 信号；实盘由平台发送建议，用户确认、拒绝或修正后才更新实际持仓，平台不自动下单。

| 聚宽侧能力 | Easy Quant 接入方式 | 时间语义 |
| --- | --- | --- |
| `get_all_securities` | `context.universe()`；证券基础信息由管理员刷新 | 决策时点前已上市的沪深京证券 |
| `get_price`、`get_bars` | `market.daily-bars` | 盘前/盘中不含当日收盘，盘后可见当日收盘 |
| 市值查询 | `market.value` / `market-values` | 使用 `available_at` 不晚于决策时点的最新记录 |
| 财务与历史财务 | `fundamental.latest`、`fundamental.history` + `financial-indicators` | 按可获知时间过滤，禁止未来函数 |
| 质押比例 | `fundamental.latest` + `pledge-ratios` | 同上 |
| 行业成员 | `fundamental.latest/history` + `industry-memberships` | 本期通过通用 CSV 导入维护 |
| RSI、MACD | `technical.rsi`、`technical.macd` | 只消费当时可见的日线序列 |
| 定时回调 | 三阶段钩子 | worker 按交易日历和交易时段触发 |
| `order_target` | 返回策略信号 | 回测撮合；实盘仅生成待确认建议 |
| `get_current_data` | `context.current_price()` 与仓位上下文 | 仅盘中实时行情；触发价和仓位由平台再次校验 |

## 离线验收

`backend/tests/acceptance/test_large_number_capability_mapping.py` 使用版本化 fixture 验证：

1. 市值、财务、质押、RSI 可联合完成选股；
2. 盘中信号可携带买卖触发价；
3. 盘后三阶段代码能够执行并输出结果；
4. 回测撮合测试另行验证盘前开盘价、盘中开收盘均值触发和盘后收盘价；
5. 实盘测试验证平台在当前价命中触发价且仓位符合要求时才创建通知建议。

行业分类、停复牌、涨跌停等字段若策略实际使用，必须先按数据契约导入并声明依赖；缺少任一依赖时平台阻断回测或实盘分析，不允许以 Mock 数据替代。
