# 实盘资金预留与操作管理

建议保持与实际成交分离：生成有效建议时原子预留买入现金（含预计费用）或卖出数量，后续策略与人工操作不得消费其他待处理建议的预留。确认或修正后以实际成交入账并释放本建议预留，拒绝释放预留；暂停仍保留预留，终止不抹去未核对建议。失败不改变账本及预留，重复请求不重复记账。

修正成交使用弹窗，标的与方向只读，数量、价格、费用预填建议值；数量必须为正整百。建议展示日期、价格、数量、状态与类型。操作列表支持搜索、分页，包含手动买卖。

用户可在未终止实盘手动录入成交，必须明确确认偏离策略与重复记账风险。现金不足时展示所需追加资金并再次确认后，原子记录注资与成交，调整资金池；不得占用其他建议预留。卖出不得超过可用持仓。请求须幂等、归属隔离、事务回滚。

平台库支持预计持股数与单标的等额预算：买入 10% 表示该标的预算的 10%，不是总资金的 10%；同次调用和跨轮待处理信号均扣除预留。示例限制标的数量及预算，快测/回测由现有模拟成交快速完成闭环。已锁定策略版本不改写。

展示收益、收益率及启动以来曲线，按真实可获知行情估值，注资不计收益；初始持仓缺估值时明确无法计算，不伪造收益。暂停/终止均二次确认，异步失败可重试，360px 不产生页面横向溢出。

验收覆盖超额连续信号、跨轮预留、确认/拒绝/修正释放、费用精度、其他预留保护、手动超额注资及幂等、权限、估值缺失、分页搜索、确认取消与窄屏。
