# 实施计划

复用持久 JSON 状态及 LiveTrackingStore 短事务，不新增表、外键或中间件。领域纯函数从待处理建议派生预留，避免双写余额；生成与处理均在同一事务验证最新账本。策略调用获得实际组合和预留，库函数实现单股预算与调用内预留，平台最终校验防止动态代码绕过。手动录入沿用操作与账本、审计及用户隔离幂等键。

服务提供组合估值和分页搜索操作查询。行情只使用已获知的记录；历史点随分析保存，现金注入从收益扣除；缺失行情/初始持仓基准时标明不可估值。前端复用 Dialog、ConfirmAction、Table、分页与图表。

宪章检查：仅低频辅助记账、无自动下单；金额 Decimal、注入时间、受限子进程；保持策略版本生命周期；边界经端口；测试 fake/内存且无真实存储及第三方网络；同步 docs。按 Ruff、前端格式/lint、pnpm check、受影响 Playwright、pre-commit 验证，分支提交推送 PR。
