# 实施计划

## 宪章符合性

- 沿用单 worker、现有行情仓储和受限子进程，不增加队列、服务或交易执行能力。
- 快测时间窗口只读取历史交易日；各阶段继续按可获知时间过滤，保持时间一致性。
- 数据库继续按 UTC 规范存储；仅展示层转换明确时区，避免隐式依赖运行环境。
- 回归测试使用内存行情仓储和子进程，不访问真实数据库或外部网络。

## 方案

1. 从交易日历选取目标日前 5 个交易日，以最早一天为查询下界；无历史日时仅查目标日。
2. 子进程 JSON 传输采用独立上限，标准输出仍按每阶段字节数单独限制。超传输上限给出专门错误，不写入原始 JSON。
3. 后台任务页以 `Asia/Shanghai` 格式化 API 的 UTC ISO 时间；更新使用文档。
