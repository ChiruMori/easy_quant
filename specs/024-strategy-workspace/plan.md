# 实施计划

扩展策略版本的状态、名称、说明与编辑修订号；无外键迁移回填历史元数据和状态。领域保持不可变值对象，通过替换草稿记录保存；回测入队与锁定状态同事务提交，实盘关联作为状态提升与编辑检查的双重保障。策略仓储提供版本分页投影，列表不读取全部源码。现有资源生命周期互斥锁保护编辑、复制、回测、实盘与删除，不新增基础设施。

新增草稿更新、指定版本复制、详情与分页接口；原有策略列表接口保留给现有页面，新增工作台使用真正的服务端分页。快测传入当前代码，worker 结束清除临时代码；旧快测接口保留兼容，但同样捕获本次执行内容。

重写工作台为列表、详情和编辑视图，复用共享 IconButton、ConfirmAction、DeleteResourceButton、表格、分页、下拉和 Accordion。编辑器右侧显示公共库，搜索和折叠使用库组件。更新旧深链接及验收用例。

宪章检查：无高频/自动交易/公共注册/分布式扩展；因子与策略分离；领域不依赖外部边界；回测/实盘版本锁定与数据血缘保留；测试仅 fake/内存/fixture；迁移无新增外键。按用户本轮要求，草稿原地保存替代此前“每次保存产生版本”，同步 AGENTS 与当前文档。

运行 Ruff、前端 format/lint:fix、pnpm check、pre-commit、受影响及全量 Playwright；检查桌面与 360px 截图，在功能分支提交推送并创建 PR（依赖未合并的 PR #14）。
