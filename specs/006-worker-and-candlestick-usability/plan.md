# 实施计划

## 宪章符合性

- 仍使用现有 MariaDB 与单 worker；不新增队列、缓存、交易执行或外部服务。
- 快测保留固定交易日、三阶段可见性和受限策略子进程。有限观察窗口明确披露，避免隐式全史扫描。
- 日/周/月只由已同步的不复权日线聚合，不引入新供应商或未来数据。
- 测试使用 fake 和 SQL 编译，不接触真实数据库；本地数据库只用于只读诊断。

## 方案

1. 分页底栏采用可换行的独立信息区与等高导航控件；去除强制 1024px 页面最小宽度。
2. 引入 ECharts K 线及内外双 dataZoom，使用日线纯函数聚合周/月和 A 股语义色令牌。
3. 快测读取所选交易日前 120 个自然日及当日行情；新增日期优先索引支持范围查询。该窗口适合示例均线策略，并在页面说明更长回溯应使用专门范围的回测。
4. worker 在任务生命周期打结构化、安全的运行日志；后台任务 API 返回租约过期判断，页面轮询展示异常，保留失败时的数据库状态记录。

## 权衡

- 120 自然日窗口不等于完整历史。超出窗口的自定义长周期因子可能得到“数据不足”，不能被误认为全史信号。
- 交易日索引迁移需扫描既有日线表，18M 行量级执行时应预留维护窗口；迁移之前快测虽有边界，但仍可能全表扫描。
