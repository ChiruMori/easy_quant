# 全页面 UI 缺陷检查与修复

## 范围与验收

- 检查登录、邀请注册及全部已注册的研究、实盘、通知和管理员路由。覆盖 360px 手机、768px 平板和桌面；宽表格、代码在自身容器内滚动，标题和操作不得被挤出页面。
- 修复侧栏账户退出文案截断、移动导航缺少关闭按钮、表单标签缺失及多个建议修正表单 ID 重复。加载失败必须展示错误，切换详情不得保留上一实例内容。
- 保留浅灰底、白卡片、蓝色强调及现有业务流程；不新增交易、注册、后端、数据库或基础设施能力。
- 用离线 E2E 内存环境和固定展示 fixture 验证路由、长文本、空态和失败状态；线上已由用户完成登录，只读检查受保护页面；写入和失败演练仅在本地内存环境进行。
