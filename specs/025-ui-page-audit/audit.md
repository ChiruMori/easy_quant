## 问题与修复

| 问题 | 影响范围 | 当前结果 |
| --- | --- | --- |
| 手机侧栏没有可见关闭按钮 | 所有已登录页面 | 保留右上角关闭按钮，并提供中文可访问名称 |
| 账户名与退出操作挤在同一行，长用户名遮住操作文字 | 桌面和手机侧栏 | 分行显示，长用户名可通过悬停查看 |
| 表单内容与页脚按钮相贴 | 注册、通知、回测创建、定时任务 | 表单容器统一保留间距；登录使用相同结构 |
| 单股票输入框被按钮挤压 | 范围拉取 | 手机采用上下排列，宽屏保留同行 |
| 股票详情页头不换行 | 股票详情 | 标题与返回入口允许换行，长名称可断行 |
| 选择框缺少标签关联或长值超出容器 | 回测创建、范围拉取、通知、建议修正 | 标签关联具体控件，选择框和弹层限制可用宽度 |
| 同时展开多张建议修正表单产生重复 ID，三按钮行挤出窄卡片 | 实盘建议 | 每个表单使用独立 ID，操作按钮允许换行 |
| 实盘读取失败时停在加载状态 | 实盘详情 | 展示错误和重试按钮，重新进入时获取当前实例 |
| 空白结果缺少说明 | 因子搜索、实盘建议 | 展示明确空态 |
| 预检或导入失败没有反馈，切换数据集仍保留旧预检 | CSV 导入 | 显示错误，切换数据集或文件清除旧结果，提交失败保留重试能力 |
| 签发邀请码异常没有页面反馈 | 邀请管理 | 显示错误并允许重试 |
| 加载占位、长说明和编辑器内容可能撑开窄容器 | 共享组件及策略编辑 | 容器允许收缩，长文本可换行，编辑器在内部滚动 |

最初旧分支中的数据管理页头挤压和来源开关重复 ID 已由更新的上游页面替代，本次未把旧页面实现带回，也未将其计作本次修复。
