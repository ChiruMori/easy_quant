# Worker 会话边界

## 问题

调度读取使用共享 scoped_session，在 REPEATABLE READ 下建立旧快照；独立队列领取会话能看见刚提交的 job，但处理器沿用调度快照，误报新 backtest_runs 记录不存在。报告任务的主键只读核对确认回测记录存在，数据库隔离级别为 REPEATABLE-READ。

## 要求

- 调度与任务处理之间清理共享会话，任务读取从领取之后的新事务开始。
- 每轮开始、空队列返回、任务成功/失败、调度/领取/保存异常均释放共享会话，不把读快照带入睡眠或下一任务。
- 保持回测与入队的原子提交、独立领取/进度写入和失败恢复；不增加重试或忽略真实不存在记录的错误，不新增外键。
- 不修改真实业务数据；自动测试使用离线、确定性的 REPEATABLE READ fake。说明重启 worker 生效，已失败任务不自动重跑。
