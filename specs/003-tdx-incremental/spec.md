# 通达信每日增量日线

管理员在完成全量导入后，通过 CLI 或现有 worker 定时任务下载官方按日 ZIP，持续维护沪深京不复权 A 股日线。借鉴 tdx2db 的 COD/MD1 原生解析和官方节假日来源，保留 MIT 声明；不引入其数据库、外部可执行程序或分钟行情。

## 验收契约

1. 逐日下载 `g4day/YYYYMMDD.zip`，全包预检三市场 COD/MD1 配对、日期、长度、引用范围、重复代码、CRC 和行情数值；无效包不写任何行情。
2. 以 `tdx-md1-v1` 归一化为现有日线契约，价格元、量股、额元、不复权；与历史 DAY 的价格和 float32 成交额口径一致，保留包 SHA256。
3. 当日 18:00 Asia/Shanghai 前不导入当天；未来日期拒绝。周末和官方 `gbbq.zip/zhb.zip/needini.dat` 已声明年度的节假日跳过；未知年度不猜测节假日。404 保持待发布，不推进为成功。
4. 一天全部行情、证券、交易日和完成记录同事务。股票/日期业务键 upsert；同摘要重跑跳过；最近七个自然日重新下载核验来源修订。失败或待发布日期后续优先恢复，不被后续成功日期掩盖。
5. 默认从已有全量导入检查点的最新日期后开始；全量导入必须先无失败完成。可显式指定起止日期做补数。单次日期范围最多 90 天，长缺口要求分段补数或重新全量导入。
6. CLI 返回 JSON 报告并在有未解决日期时非零退出；worker 注册独立任务类型并使用已有调度/任务记录，失败可观察。自动化测试完全离线。

不包含复权因子、股本变动、更名历史迁移、证券名称补全及全市场策略加载优化。休市日历只用于本增量任务，不把缺失的交易日期伪装成休市。
