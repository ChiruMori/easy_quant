# 采集数据库错误分类、恢复与性能修正

附件异常为raw_cache.merge读取旧缓存时的MySQL 2013，不属于来源失败。数据库/配置错误必须立即记录脱敏堆栈、错误类别与采集上下文，并终止当前任务；不得触发来源切换、5/10分钟来源退避或跳过失败标的后继续。无法保存失败状态时日志明确说明，不假报已记录。

只对明确幂等的数据库操作支持一次局部恢复：断连废弃连接，死锁/锁等待回滚事务，再重做该数据库操作，耗尽立即失败，不重新抓网络。网络和限频等待前释放采集读事务，缓存写入直接upsert，不merge读取大BLOB。权限/库表/字段/约束等错误不重试。

接口请求仍至少间隔5秒且跨领取保持预算；无网络步骤、已新鲜标的、已完成范围不额外等待。等待期间不每秒查询整条任务，发请求前按租约字段校验。逐股按有界游标读取、批量查询检查点，财务版本查询只投影元数据并筛选当前报告期，保留幂等与可见时间语义。

不改K线结构或真实数据，不新增大表/外键，不扩大架构。所有回归离线，覆盖错误日志脱敏、永久失败、局部恢复、不重新请求网络、事务释放、请求节奏和查询形态；更新当前文档并沿用PR27。
