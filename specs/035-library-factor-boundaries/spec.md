# 平台库函数与即时因子

库函数直接提供平台管理的数据（K 线、无需计算的财务等），各自可拥有适配器、同步任务、依赖与存储，不建立通用插件调度框架。因子是需要计算的派生结果，随应用发布、每次调用计算、不持久化。

回测开始前批量加载历史并预热；执行因子只读运行快照，不逐次访问数据库。数据始终受 available_at 决策时点约束。因子可调用库函数，库函数不得依赖因子。因子通过声明默认参数、校验及数据依赖扩展。现有策略的数据读取 factor 调用保留兼容转发，但不出现在因子目录。

验收：目录仅含计算因子；library 可读取 K 线及财务；相同快照计算一致，未来数据不可见；多次计算不重复读取数据端口且修改返回记录不能污染快照；三个运行时及历史窗口推导支持 library 调用；既有策略继续运行。机器学习示例不实施，不新增模型管理、自动交易或服务。
