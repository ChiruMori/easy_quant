# 资源删除与控件一致性

策略删除前列出快测、回测数量并二次确认，确认后由业务代码清理全部版本和关联测试。任何状态的实盘引用均阻止策略删除，提示实盘名称及先手动删除实盘数据。正在执行的关联任务阻止删除，避免 worker 写回已删除数据。

仅已终止实盘可删除；业务事务清理建议、实际操作、账本、定时任务、通知投递及后台任务。未启用且未被任何实盘引用的通知渠道可删除；阻止时显示具体实盘名称，兼容旧实盘默认使用全部本人渠道。

所有删除和刷新停复牌状态使用二次确认；异步失败保留对话框并显示原因，提交时禁止重复操作。所有日期输入使用共享 shadcn Calendar + Popover，保留表单字段、日期格式与键盘操作，验证 360px。

非 root 后端镜像预建并授权本地缓存目录。删除链路现有外键用专项迁移移除，不增加外键。验收包含权限隔离、关联阻止、级联完整性、事务回滚、取消不请求、失败反馈、窄屏和容器目录权限。
