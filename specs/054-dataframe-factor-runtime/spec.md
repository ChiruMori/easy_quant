# DataFrame 研究计算与因子运行观测

研究数据统一提供 pandas DataFrame / float64，因子使用浮点序列算子；策略可使用受限 pandas、NumPy、TA-Lib。明确总体标准差、EMA 首值种子和缺失/非有限值规则，不因切换数值类型改变 PIT 边界。既有 DECIMAL、压缩行情、JSON 数字字符串通过读取边界兼容，不重写、不清空；资金账本继续明确舍入的 Decimal，研究结果在信号边界转换。旧策略允许 Decimal 作为兼容入口，但新示例采用 float。

因子目录提供同步弹窗快测：填写决策日期、证券及因子参数，仅查询对应依赖数据，不采集、不 Mock；最多500只、2500个交易日。计算在受限子进程完成，包含数据准备的预算检查及计算硬超时；失败/超时有明确反馈。

回测与实盘通过 context.factor 实际调用时统计次数及总耗时（包括返回不可用和抛错，排除独立因子快测）。子进程回传阶段增量，由父进程持久化；同一次回传重复写入须幂等，支持并发累加。列表展示次数、总耗时和平均耗时；无调用时均值为空。被强杀且未回传的调用无法计量，明确披露。

复核剩余阻塞因子，仅启用现有规范数据能可靠支持且维护成本合理的项目。缺少 PIT 数据、定义或历史事件的项目不伪造替代值。

验收：老数据字符串/Decimal转换、float64类型、浮点容差、缺失/未来数据隔离；真实子进程 DataFrame 策略与非法I/O拒绝；快测成功、非法参数、缺数据、硬超时；统计回测/实盘接线、失败计量、幂等并发SQL；弹窗等待/失败重试、360px布局。

已确定启用9项：npm_q/npm_y/npm_ttm、opm_y/opm_ttm、asset_turnover、receivable_turnover、equity_turnover（显式股票池排名），及sales_to_market（单季营业收入/市值）。旧报表仅从保存的原始独立科目投影新营业收入字段，缺少原科目不猜测。
