# 实施计划

宪章检查：仅日线数据与停牌元数据；复用采集端口、任务队列及记录仓储，不增加表或外键；网络在适配器内使用既有超时，测试用内存与 MockTransport。回测不增加网络调用，不推断或补造缺失行情。

1. 增加东方财富批量停牌适配器，校验分页完整性，以明确日期区间及整日时段确认停牌；原始供应商字段留在适配器边界。
2. 接入状态采集、审计快照、盘后流程及手动刷新；证券清单正确识别显式停牌；对原停牌且当天名单未确认停牌的少量股票，使用已启用日线源自动确认当日成交并恢复交易，随后自动纳入日线批次；仍停牌的股票跳过日线。
3. API 和页面统一停牌展示；补充回测与页面离线回归并同步文档。
4. 执行 Ruff、前端格式检查、pnpm check 及受影响 Playwright。

失败模式：停牌来源不可用则任务失败并保留原状态；完整空名单仍需真实成交证据才能恢复；确认来源失败或空数据保留停牌并报告待确认，下次盘后自动重试；预计复牌时间不代表已复牌。复牌确认只探测原停牌的候选股票，不扫描日线明细；证券状态分组批量更新。退出路径：禁用该数据集来源，人工入口仅作异常修正。
