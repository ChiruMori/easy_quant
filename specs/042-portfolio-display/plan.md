# 实施计划

1. 扩展现有实盘估值响应提供逐标的市值和账本成交标记，复用已有行情读取；在曲线中纳入成交时点。旧冻结快照缺新字段时显示不可估值，不追读新行情。
2. 共享 PortfolioChart 按上海交易日展示主曲线的成交标记和成交说明；页面传入回测交易/实盘完整成交。持仓表复用 Tooltip，建议比例用 Decimal 固定精度。
3. 同步离线回归、Playwright、当前文档，执行格式化、全量检查和受影响旅程，功能分支提交并创建 PR。

宪章检查：仅展示与报告契约增量；不修改交易账本、策略生命周期或权限；不增加表、外键、网络请求、自动下单或高频能力。后端估值使用 Decimal 与显式时点，测试采用 fake/内存数据。
