# 持仓估值与成交点展示

实盘持仓表展示每个标的全部持仓（含锁定股数）的预估总价值，使用既有估值时点已发布的收盘价与 Decimal 计算。缺失行情显示暂不可估值；悬停及键盘聚焦说明估值口径、延迟与终止冻结。建议仓位比例固定两位小数。

回测与实盘主曲线显示红色 B 买点、蓝色 S 卖点及小圆点，金额/收益率切换保持标记。回测来自模拟成交；实盘来自完整实际账本，不受操作列表分页、筛选影响，拒绝及待处理建议不显示。按上海交易日聚合，同日同方向合并提示，同日买卖分别展示；没有有效曲线值不伪造标记坐标。

验收：Decimal 市值及缺行情、完整账本成交与冻结语义离线验证；浏览器验证买卖标记、两种单位、估值说明、两位比例、360px 及桌面布局、估值失败重试。
