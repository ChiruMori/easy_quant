# 基本面采集可靠性、存储与报表

修复证券及估值来源不可用、分红提前公告被整页拒绝、状态重复快照及历史重复拉取。实际来源低频探测与数据库只读诊断独立于自动测试；不得修改真实数据或执行迁移。

同内容状态保留首次可见时间，状态回变仍保存新事件。来源异常含股票、数据集、报告期；不因合理的提前分红公告拒收，时间存疑的财报按观测时点可见。历史检查点保留，失败页可恢复；日线补缺不依赖全量重跑。

股票详情增加报告期图表、指标切换和主营构成；缺失留空并明示，不合并重复修订或不同分类构成，不混加累计季度。管理员可按股票和数据集补采，普通用户不可写。360px与桌面、异步失败重试及离线回归须验证。

旧报告完成后不再定期全范围重抓，较早修订可通过范围拉取/单股补采获取；近期报告仍做全市场分页复查。逐股日线/主营每请求至少5秒，全部股票都需请求时仍可能超过10小时。日线补缺仅查询已有覆盖的近五年交易日；旧缺口尝试后30天复查、近期7天缺口每日复查，不伪造停牌期间数据。状态历史只读折叠，不清理真实旧记录。大JSON编码需API与worker同步升级，回滚须保留解码兼容。
