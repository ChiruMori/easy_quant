# 运行反馈、按需历史与定时任务控制

## 要求

- 写操作从请求发出到响应解析使用统一全页加载遮罩，阻断鼠标和键盘重复操作；简单操作可使用按钮 pending。读请求及后台轮询不遮罩，失败后释放遮罩并显示错误。
- 管理员可手动执行定时任务（停用时也可执行），复用 worker 与原任务配置，不改变下一次计划时间；同一幂等键只创建一个任务。停用计划可编辑类型、表达式、时区、配置；启用计划需先停用。校验失败不改变原计划，启用重新计算下一次时间。
- 回测区间独立于滚动历史窗口。可静态识别的因子使用最大需求作为预热窗口，MA5 预热 5 个交易日；固定末尾索引的原始日线只需要实际引用的尾部长度，现有均线示例的 `bars[-1]` 不扩大预热。动态历史访问保留 250 日默认及显式 HISTORY_TRADING_DAYS 上限 2500。快测同样按需求取历史，Mock 必须显式开启。
- 在执行策略之前检查区间覆盖；上市时间晚于区间起点不误判为数据缺失。停牌不要求每天都有成交日线，不补造数据。缺失报告保存结构化数据与修复入口。
- 回测状态包含校验、预热、取数、当前交易日/hook、快照与保存；状态独立短事务持久化，长读事务及失效连接不能遮蔽失败原因。每个阶段开始输出日志，逐日进度限制写入频率。
- 回测与快测保存阶段耗时、三个 hook 的次数/平均/最大耗时及逐日 hook 耗时；失败保存已经完成的统计。计时为宿主观察的执行耗时（含进程交换），不能当作纯 CPU 时间。

## 验收

离线验证 MA5 小窗口和多年完整推进、未知需求回退、上市与缺失边界、策略执行前缺失失败、失效 Session 后失败可见；前端验证延迟写请求遮罩与失败释放、状态/耗时/缺失显示、停用编辑及手动任务重复键；受影响 Playwright 旅程通过。
