# 实施计划

保留日线、单 worker、人工交易、邀请制和纯领域核心。只修改持久化边界与查询/缓存策略，不引入 Redis 或分布式队列。

1. 读取日志及只读锁/事务元数据，不输出连接凭据、任务载荷或联系方式；所有诊断查询限时且样本有界。
2. 根据真实锁证据修复领取事务生命周期，限制领取行数；验证空队列返回与异常均清理锁，必要时将 jobs 使用独立短事务。
3. 审计现有按月运行流、快测/实盘页缓存、日线上传与快照查询。保留高效路径，替换已确认的逐行往返、重复读取及扫描。
4. 基于字段使用与样本空间，提供有必要才执行的存储迁移，不将 future schema 写成当前已部署状态。
5. 离线 fake 与版本化 fixture 验证，Ruff、pnpm check、受影响 Playwright；真实库仅 SELECT/SHOW/EXPLAIN。
