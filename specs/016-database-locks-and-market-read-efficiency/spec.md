# 数据库锁与日线读取效率

## 要求

- 当前数据库仅允许只读诊断，不执行数据修复、KILL、DDL、迁移或配置全局修改。
- 任务领取事务必须短且有界：只领取一个任务；空队列及异常路径释放锁，不允许锁跨越策略或行情分析。空队列轮询不阻塞新任务入队，回测提交失败不遗留无法执行的排队记录。
- 审计大日线表的逐行查询、重复全表摘要、单日预取、低密度投影和跨任务缓存。按实际股票与日期批量读取，优先利用已有主键/索引；缺页按所在区段获取、有界 LRU 淘汰，不跨任务隐藏数据修订。
- 批量写入不能为每根 K 线 get/merge；保留覆盖数、复权校验、同一事务与确定性结果。
- 审计重复字段实际用途与空间；无作用的字段移除，有血缘/时间一致性作用的字段不得直接删除。若需结构压缩，提供可执行或分阶段迁移方案、校验与回滚步骤；本轮不对真实库执行。
- 离线回归覆盖锁释放、单任务领取、批量查询数与 LRU、资金/快照等价及迁移兼容性，同步文档并完成质量门禁。
