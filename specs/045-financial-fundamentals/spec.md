# 财报、基本面接入与股票全景详情

## 范围与约束

接入合并口径资产负债表、利润表、现金流量表（历年年报/中报/一季报/三季报）、主要财务指标，以及公司概况、分红送配、股东户数/股本、主营构成。复用已有估值、质押、行业及证券风险数据。原始接口优先，三大报表和指标注册东方财富、新浪独立直连接入与失败切源；能直接分析的接口不再经 AKShare 转发。全部接入数据在后台数据集同步/盘后任务可获取，在平台库、快测、回测和实盘可读取。

不得改动任何 K 线数据、结构或迁移；不新建 K 线同规模数据表。复用 market_records，必要时扩容 payload、增加标的索引，不新增外键，不对真实库执行迁移/全市场回填。需要突破以上边界时停止并请用户确认。

## 数据语义

- 明确股票、报告期、报表类型、累计/时点口径、币种、单位、原始字段及来源。金额/比例有限 Decimal，缺失为 null，百分比标准化为百分数；不将累计利润/现金流误称单季。
- 公告日期不等于报告期。可信来源修订时间存在时，可获知时间取公告日结束与来源修订时间的较晚者；无法证明版本时间时按采集时点保守可见。不得把最新修订值按最初公告倒灌历史。发现同逻辑记录内容变化但未更新版本时间时，新版本按采集时间可见。
- 保存内容身份及修订历史，重复采集幂等且不更改原可见时间。平台库按决策时间过滤，并按报告期选取当时可见版本，旧报告新修订不能盖过更晚报告。来源差异保留血缘，不混合不同来源拼凑同一报表。
- 分页和日期批次完整校验，错误响应、非有限数值、错标的不得缓存为成功。空的有效数据可表达未披露/不适用；来源错误必须报告失败与可重试状态。已成功股票可保留，失败股票有明细。
- 不持久化公司联系方式、电话、邮箱、地址或人员信息；概况仅取经营与证券相关安全字段。

## 用户体验与验收

股票详情展示证券资料、公司经营概况、最新估值/风险/行业/质押、主要指标、三大报表历史、分红、股东与主营，提供报告期、来源、公告/修订/采集/可见时间和完整字段查看。按数据集分页与独立加载/失败重试；不存在的数据明确为空，不生成演示值。登录用户只读，采集/配置仍管理员操作，窄屏无整体溢出。

验收覆盖来源分页/批次/切换、字段与单位、年报季报、不同来源与修订、幂等及未来数据隔离、策略依赖与子进程传递、持久化索引与无外键迁移、详情所有已保存数据、权限和1440/360px浏览器旅程。网络探测独立于完全离线自动测试。
