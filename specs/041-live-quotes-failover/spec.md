# 实盘报价容错与失败告警

实盘报价优先尝试独立来源，按轮遍历全部候选来源，全部失败后再重试一轮。空数据、缺失标的、非有限或非正价格必须在来源成功之前校验，以便切换来源；禁止用旧缓存、历史收盘或Mock代替失败的实时价格。

每次来源请求记录数据集、来源、轮次、异常类型、脱敏原因及耗时。最终异常保留全部尝试记录。全部来源失败时，不提交策略状态或建议，不消费阶段完成标记；通过实例选择的本人通知渠道发送幂等告警，通知失败不能覆盖采集原始异常，持久outbox可恢复。

核查已注册来源。只有证据支持固定失效时才移除，不能把一次断连当成永久失效；备用来源只获取指定标的，不读取全市场。不新增服务、表或外键，不改K线数据。
