# 研究工作台交互与专业代码体验

- 实盘运行计划使用可识别的卡片、图标和展开按钮，暂停时仅允许本人编辑时间表达式；运行与终止状态只读。保留五段 Cron、时区和阶段；无效表达式、跨实例或其他字段更新均拒绝且不部分写入。
- 用户时间表达式在恢复和 worker 轮询中保持有效，不被统一盘中时刻覆盖。终止后只停用计划并保留配置，实例删除后才清理。已被旧版清除的计划不伪造历史配置。
- 回测、快测、策略详情的策略代码预览统一为有工具栏的容器/弹窗，采用本地打包的 Monaco，支持 Python 高亮、行号、搜索、折叠、复制和放大预览。策略编辑同样使用 Monaco，提供自动缩进、括号配对、代码片段及平台接口补全；不宣称提供 Python 类型检查或执行。
- 主要可点击功能使用按钮、图标及主题色，减少裸下划线入口；列表链接可保留但有明确颜色和图标提示。
- 共享图表使用 ￥/% Tabs 切换，与添加比较和标签保持统一高度及视觉密度。
- 桌面和 360px 验证编辑、只读、高亮、加载/失败反馈、键盘操作及布局，不能因编辑器加载阻塞页面其他功能。
