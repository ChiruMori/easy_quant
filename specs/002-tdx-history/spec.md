# 通达信全量 A 股日线接入

日期：2026-10-02。范围：下载个人版官方沪深京日线完整 ZIP，筛选 A 股，解析历史日线并导入已配置 MariaDB。原始包不进入 Git。提供 CLI；本次不扩展分钟线、自动交易、分布式架构或浏览器大文件上传。

## 验收

1. 固定 `.day` 样本准确解析日期、价格（整数分）、成交量（股）、成交额（元），以 Decimal 规范化；原始数据为不复权，日线可获知时间明确为交易日 15:00 Asia/Shanghai。
2. 支持 ZIP 内正斜杠和反斜杠路径；只接受沪深京 A 股代码，不导入指数、基金、B 股和转债，不解压不可信路径到文件系统。
3. 下载流式落盘，校验 ZIP；每只股票预检后批量写入，记录包 SHA256、来源、口径及进度。错误不得静默跳过；同包重跑可跳过已完成股票，批次失败可安全重试。
4. 日线库保持业务键幂等。不得用不复权数据覆盖其他口径的已有数据；保留既有证券名称。
5. 全量导入后数据覆盖接口使用数据库聚合，避免全市场历史在内存反复扫描。
6. 自动化验证全部离线，以 BytesIO ZIP、固定二进制样本、fake 仓储及 MariaDB SQL 编译完成；真实下载和入库单独记录实际数量、日期、摘要和缺失情况。
