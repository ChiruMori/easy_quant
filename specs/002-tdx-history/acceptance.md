## 恢复与页面

真实导入发现 float32 成交额超出数据库四位小数精度，已统一按 ROUND_HALF_UP 规范化并补回归。部分连接曾短暂断开，385 个失败代码均通过同包重跑补齐；未提交批次不产生完成检查点。数据库连接恢复后最终验收失败项为零。

本地 API 和 worker 使用新代码重启。实际浏览器数据管理页面已展示平安银行 `000001` 的 1991-04-03 至 2026-09-30 共 8,464 条记录，以及其他沪深京数据。旧默认日线说明已显示公开接口前复权、通达信不复权；来源启停配置保留。

全量完成后的真实 HTTP 验证：登录返回 200，覆盖接口返回 200，报告 6,157 个代码与 18,394,971 条记录；本次端到端覆盖接口耗时 25.06 秒。
