# 后续推进顺序

基于 2026-10-02 当前代码及通达信入库验收，以下是未纳入本次修复的工作，需分别形成可测试规格。

1. **全市场策略与回测的数据读取边界**：目前策略试运行/实盘读取全市场全部历史，回测读取区间内全部股票。应显式声明证券范围、因子依赖和 lookback，提供有界查询与迭代读取；不能用静默截断历史改变因子结果。回测改为后台任务并保留进度、取消和失败恢复。以已入库约 1,839 万行验证内存、响应时间和结果一致性。
2. **完整实际组合基线与人工成交信息**：初始现金/初始持仓/成本必须形成不可变基线，支持成交时间及备注。为已存在无效账本提供只读诊断、人工核验和可审计修正，避免直接改写历史。
3. **复权及证券身份**：当前通达信日线不复权。接入公司行为、复权因子、退市/更名映射，明确因子和回测对分红、送股的处理；不可把当前不复权直接覆盖成前复权。
4. **数据任务可视化与运行保障**：展示全量/增量进度、最近成功交易日、缺包清单、失败恢复入口；确认部署 worker 及增量计划启用情况，建立失败诊断。计划存在不等于成功更新。
5. **结构化实盘存储及可靠通知入队**：替换现有持久 JSON 状态并迁移已有数据，保留端口和事务语义；建议与通知 intent 同事务记录，worker 安全投递，避免提交建议后崩溃遗漏通知。
