# 实施计划

## 宪章符合性

- 只处理已有日线和证券目录，不增加交易执行、服务或数据供应商。
- 状态由同步服务决定，仓储实现负责持久化；策略运行只读取标准化目录状态，不依赖 Web 或数据库模型。
- 使用离线 fake 和内存仓储测试，保留历史行情与已有回测的审计记录。

## 方案

完整证券清单成功取得后，先写入清单中的活跃证券，再将既有但不在清单中的股票设为 `delisted`。空响应拒绝执行批量退市；局部刷新不做差集。覆盖接口把退市状态置于同步跨度和数据新鲜度之前。三条策略运行路径在读取目录后过滤行情与基础记录，并在输出边界再次过滤信号，防止硬编码代码绕过标的池。回测快照采用同一过滤集合。
