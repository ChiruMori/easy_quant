# 实施计划

1. 实盘计划用显式实例生成，在创建实例的短事务中一起保存；调度对缺计划实例修复。
2. 独立行情扫描复用物理主键批量读取与一次来源字典，按月/交易日排序；一边加载一边留存快照，去除结束后的二次扫描。采用快速gzip等级，保留摘要和现有解压契约。
3. 因子输入深拷贝改为冻结原始数据及返回隔离副本，减少每阶段反复处理；子进程读写统一deadline，退出/超时细节可诊断，保持资源限制。
4. 离线回归、规模实验及当前文档，运行完整检查与受影响浏览器旅程后功能分支交付。

宪章检查：显式端口与纯计算边界不变；不新增表、外键、服务或跨任务缓存；快照来自实际输入而非事后变化的数据；不读取未来数据、不改策略版本/人工账本；测试只用fake/内存和固定输入，不连接真实数据库。真实服务器磁盘/数据库耗时需部署后确认，离线验证查询复杂度与有界历史。
