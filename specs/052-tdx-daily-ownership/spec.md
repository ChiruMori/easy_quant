# 通达信日线归属与聚合退避修复

以已验证的历史不复权、元/股/元口径为准，不切换复权或重建大表。A股自动日线仅由现有通达信整日批量管道更新；聚合基本面任务不再逐股获取股票日线，保留旧任务范围索引并安全跳过旧日线游标及其失效失败记录。独立指数计划保留。

通达信已管理股票不得通过公开日线采集入口覆盖，写入边界也提供保护。通达信增量默认摘要幂等保持；增加必须显式提供起止日期的replay入口，允许已成功同摘要日期按官方整日包恢复被其他来源覆盖的行，不自动执行修复或改库。

正常请求仍按请求开始至少间隔5秒；普通来源故障按15/30秒短退避、最多三轮。真正HTTP429保留5/10分钟退避，合法Retry-After可指定等待。进度明确显示等待秒数及失败/限流区别；数据库故障不走来源重试。测试完全离线。
