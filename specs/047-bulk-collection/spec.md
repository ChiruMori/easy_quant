# 批量、限频、可续传的数据采集

替代按数据集乘20股产生数千子任务的编排。一个采集运行只有一条聚合后台任务，按页/标的保存进度并让出worker；全部范围处理结束前不显示成功。保留真实保存数量、来源覆盖、当前数据集、报告期、页码、失败及剩余范围。

七类财报基本面优先全市场分页接口（500条/页），先覆盖全部股票最新报告，再补历史。不能批量的主营与已有个股日线使用同一聚合任务的低频游标，不新建逐股票任务。已完成历史按刷新周期跳过，避免每天重复回抓五年。单次网络请求至少间隔5秒、无突发并发，429/限流退避，异常重试有限；所有HTTP尝试/分页都受控，不以减少任务数掩盖HTTP洪泛。删除/取消/失去租约后停止后续请求。旧nightly分散任务不再执行或补建。

后台列表一条运行展示分页进度、保存/未变化/失败计数；支持重启续传，不把派发视为采集完成。去掉数据管理自动采集卡片，保留系统管理定时任务及后台任务入口。

保留原数据、财报版本和可见时间，不修改K线表结构、不新建大表或外键，不自动在真实库回填。批量接口提供报表关键科目；既有完整个股细表可按需补采。源站未披露/不适用明确为空，不伪造全覆盖。
