# 系统架构

Easy Quant 是面向少量受邀用户的单机、前后端分离应用。React SPA 通过 `/api/v1` 调用 Flask API；同一后端包还提供轮询 worker。API 与 worker 在开发、测试部署和生产环境都使用配置的 MariaDB，不存在运行时易失存储模式。自动化测试仅通过显式依赖注入使用离线 fake，不对应任何应用运行环境。

## 模块边界

- `backend/src/easy_quant/domain`：领域实体、交易日历、账本和回测计算，不依赖 Web、数据库或网络。
- `application`：身份、数据获取、策略、通知、审计和调度用例。
- `infrastructure`：AKShare、东方财富、CSV、SQLAlchemy、通知渠道和策略子进程适配器。
- `api`：鉴权、CSRF、统一响应和 HTTP 路由。
- `worker`：读取持久任务，执行每日行情更新、实盘三阶段分析和通知重试。
- `factors`：随应用发布的只读因子注册表。
- `frontend/src/features`：按数据、因子、策略、回测、实盘、通知和系统管理组织页面。

SQLAlchemy 会话按线程隔离，API 在每次请求结束时释放会话；worker 每轮轮询前释放上一轮会话，重新读取持久状态。持久化列表在 API 边界转换为普通列表后返回 JSON。

## 运行拓扑

开发时运行 Vite `5173`、Flask `5000` 和可选 worker，Vite 将 `/api/v1` 代理到 Flask。生产编排包含 Nginx、API、worker、一次性数据库迁移和 MariaDB。API 和 worker 分别建立数据库会话，通过持久任务和业务幂等键协作。

系统不含 Redis、Celery、对象存储、分布式协调、券商连接或自动下单能力。盘中监控只读取当前报价，不保存分钟或逐笔历史。
