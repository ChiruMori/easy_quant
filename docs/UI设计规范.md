# UI 设计规范

本规范以现有 React、Tailwind CSS、shadcn/ui 与 Tremor 页面为基础。数据管理页是列表与配置并存场景的参考实现；策略、回测、实盘等页面沿用共同的标题、反馈和响应式规则。

## 信息与导航

- 侧栏承载稳定的业务模块，同一模块的对象类型使用页面内 Tab。指数归属数据管理的第二个 Tab，不重复设置侧栏和快捷入口。
- 桌面展开/收起控制位于侧栏品牌行，展开时靠右；收起后顶部品牌图标在悬停或键盘聚焦时显示展开图标与提示，点击展开。主内容页头只在手机保留导航入口。
- 使用共享 `PageHeader` 展示标题、简短说明与主要操作。多个低频维护操作归入一个菜单；数据管理统一使用“数据维护”。
- 优先展示名称和业务状态，编号作为辅助信息；相关对象提供有明确名称的详情链接。
- 文案使用中文，代码和协议保留原文。描述当前真实能力，不把数据覆盖、回测收益或来源响应表述为保证。

## 布局与密度

- 使用现有主题 token 与共享组件，不为单页另建颜色或字号体系。主标题、卡片标题、正文、辅助文字保持清晰层级；辅助文字采用 `text-muted-foreground`。
- 页面按内容分区，使用一致的 `gap` 与卡片内边距。配置不应挤占核心数据的阅读面积，不将每个状态都扩大为独立指标卡。
- 数据管理在 `xl` 及以上采用左侧弹性列表、右侧 20rem 来源栏，间距 `gap-5`；较窄窗口改为单列，数据列表在前。
- 弹性子容器设置 `min-w-0`，筛选工具允许换行。选择框限制在可用宽度内，长标识与说明可换行，加载占位同样不得撑出容器。表格和代码在局部容器滚动，页面整体不得横向溢出。以 360px 宽度验证主旅程。
- 表格展示可比较的字段，长说明放在表格外；分页、搜索和筛选贴近列表，避免顶部堆叠大量按钮。

## 控件与状态

- 图标统一使用与 shadcn 配套的 Lucide（`lucide-react`）。常见创建、查看、编辑、保存、删除及可清楚表达的重复操作优先用共享 `IconButton`/`IconLink`；每个图标须有中文可访问名称与 Tooltip，禁用和等待状态仍可辨认。危险操作的确认弹窗保留明确文字，不用图标代替确认语义。
- 策略工作台默认展示分页版本列表，详情只读；草稿直接编辑，锁定版本从列表和详情编辑时都先确认复制。公共库在编辑器右侧，搜索位于滚动内容外，接口初始全部折叠，窄屏放到底部。
- 同一状态不重复贴标签：覆盖状态已经是“数据落后”时，不再额外显示同义的“已过时”。不同语义的覆盖不足、来源尚未发布等提示仍保留。

- 日期输入统一使用共享 `DatePicker`（shadcn Calendar + Popover），中文日历支持年月选择，保留 `YYYY-MM-DD` 手动输入和表单字段；不使用浏览器原生日期弹窗。
- 快速测试的启动图标紧随日期选择器，与日期输入框、日历按钮同一行居中对齐；日期说明放在整行下方，窄屏保持同行且不横向溢出。
- 所有资源删除与“刷新停复牌状态”使用共享 `ConfirmAction` 二次确认。删除预检展示影响范围或具体关联名称；提交时禁用重复操作与关闭，失败保留弹窗并显示原因，允许重试。取消不发送写请求。

- 操作使用 Button，导航使用 Link，类型切换使用 Tabs，菜单使用 DropdownMenu，布尔配置使用 Switch 或可表达按下状态的 ToggleGroup。
- 来源配置使用紧凑图标按钮。高亮主题色、勾选图标与 `aria-pressed` 共同表示启用；停用采用中性色和不同图标，不单靠颜色区分。
- 可逆的小配置点击即保存。提交期间锁定重复操作并显示进度；失败恢复原状态并在附近显示原因，不让界面假装已保存。
- 任务展示排队、运行、成功、失败和结果数量；部分失败同时报告已完成数量、失败对象与来源明细。请求成功但无有效业务数据不能展示为有效同步成功。
- 错误、加载、空列表均使用明确文字反馈。没有真实数据时不伪造图表、行情或默认收益；错误信息不得暴露凭据。

## 颜色与图表

- 普通状态使用主题语义 token：主要动作和启用状态用 primary，错误用 destructive，辅助信息用 muted。颜色旁始终保留文字或图标。
- 行情图遵循当前 A 股习惯红涨绿跌；这与任务成功、失败的语义不同，使用图例和字段明确说明。
- 回测与实盘复用组合图表，提供金额/收益率切换、临时市场比较和添加失败重试；回测另支持相同起止与初始配置的回测比较。图表提供单位、日期、图例和可读提示；指标卡使用共享 `MetricCard`，避免重复包装造成层级过深。

## 可访问性与验证

- 表单控件有可关联的标签；纯图标操作有业务含义的可访问名称。Tab、菜单、按钮支持键盘，保持组件的焦点样式。
- 实盘操作采用分页表格，标的/日期/说明搜索与状态、类型筛选分离；接受和拒绝使用图标并二次确认，说明独立成列，超过 15 字省略并支持悬停、焦点、点击展开全文；修正成交弹窗固定标的与方向，其余字段预填，数量整百；手动录入先风险确认，超额时显示追加资金及调整后资金池。表单字段 ID 必须唯一且标签关联到控件；移动侧栏保留可见关闭入口。表单内容与页脚按钮之间保持统一间距。
- Dialog、Sheet 提供标题；异步进度使用 status，错误使用 alert。禁用操作应能从附近状态判断原因。
- 修改交互后验证成功、失败、等待和恢复路径；自动保存验证重复点击和失败回滚。布局变更用 Playwright 验证宽屏与 360px，并查看截图。
- 前端修改运行 format、lint:fix、项目检查及受影响的端到端测试。规范随已实现的公共交互演进，未来设计放入 specs。
