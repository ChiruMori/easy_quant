# 回测与实盘

## 回测

用户选择不可变策略版本、日期、初始资金、手续费、滑点、基准和随机种子。标的由策略和因子决定，表单不单独填写股票。系统在运行前检查日线及静态可识别的因子数据依赖；缺失时返回数据集、日期范围和数据管理入口，不使用 Mock 或合成行情。

引擎按每个交易日依次运行盘前、盘中和盘后钩子。盘中回测使用当日开盘可见价格，回测路径禁用所有通知。资金、持仓、费用和指标使用 `Decimal`。结果持久保存配置、应用版本、数据快照摘要、策略输出、逐日权益、交易和中文指标；服务重启后仍可查询和比较。

## 实盘建议

只有成功回测才能启动实盘。启动时自动建立盘前、盘中固定间隔和盘后计划：盘前信号立即通知；盘中在交易时段刷新当前报价，价格达到策略阈值且持仓条件满足时创建一次幂等建议；当天出现过建议时，盘后发送持仓核对提醒。实盘不会自动下单。

用户可快速确认、拒绝或录入不同的实际成交。每次处理带幂等键和建议版本；实际操作生成不可变账本，禁止负现金和负持仓。后续策略上下文只使用账本重建出的现金、持仓和成本。

通知支持 ntfy 和邮件。通知目标加密保存，API 只返回掩码。临时投递错误进入持久重试任务，永久配置错误标记失败；业务事件与订阅共同形成幂等键，重复分析不会重复发送。
