# 因子与策略

## 因子

因子是平台代码内的只读方法，随 Easy Quant 发布，不由用户创建、编辑或单独版本化。因子目录展示说明、参数、输出结构、输出示例和调用示例。示例中的数值和日期仅用于说明返回结构；技术及统计因子的计算结果为 Python `Decimal`，数据不足时通过 `available: False` 与 `required`、`actual` 等字段说明原因。行情和基本面记录的字段会随数据集而不同，策略应先检查记录是否存在。

| 因子 | 当前能力 |
| --- | --- |
| `market.daily-bars` | 读取决策时点可见的日线 K 线 |
| `market.value` | 读取最新可见的估值与市值记录 |
| `technical.ma` | 移动平均线，`window=5` 即 5 日均线 |
| `technical.rsi` | 指定窗口 RSI |
| `technical.macd` | DIF、DEA 与 MACD 柱值 |
| `stat.expected-return` | 历史胜率和预期回报 |
| `fundamental.latest` | 指定基本面数据集的最新可见记录 |
| `fundamental.history` | 指定基本面数据集的可见历史序列 |

机器学习因子只能加载随应用发布且摘要匹配的权重，运行期不训练或上传模型。

## 策略契约

策略必须实现 `before_market(context, parameters)`、`on_market(context, parameters)` 和 `after_market(context, parameters)` 三个钩子。每个钩子返回信号列表；系统不提供旧策略协议兼容入口。信号至少包含 `symbol`、`action`、`quantity` 和 `reason`，盘中条件信号可带 `trigger_price`。

策略上下文提供股票池、当前持仓、盘中价格以及 `factor` 调用。盘前只看到此前已知数据；盘中通过当前报价判断触价；盘后可以读取当日收盘数据。页面提供“5 日均线选股”和“正预期示例”，两者与用户策略使用完全相同的保存、版本和运行机制，使用比例建议。策略公共库页面 `/strategy-library` 提供签名、参数、返回值、调用示例和运行时限制。

三个运行时共用 `RuntimeContext` 和唯一的平台因子实现。`context.position(symbol)` 返回 Decimal 数量，`context.portfolio()` 返回 Decimal 现金、持仓和平均成本。快测和回测按阶段模拟成交，下一阶段看到真实接受的模拟组合；实盘以人工操作账本为准，建议不入账。上下文是独立副本，修改它不会改变引擎账户。

`context.signal(symbol, action, ratio, reason, price=...)` 返回信号字典，需要放入钩子的返回列表。买入比例以阶段开始可用现金为基数，卖出比例以该股实际持仓为基数；比例范围 `(0,1]`，默认按 100 股向下取整，数量为零不执行。买入预留配置中的手续费和滑点，同一钩子中生成的比例建议预留计划预算，避免重复分配；这不会修改真实账本。实盘建议优先采用本阶段临时报价，其次采用信号参考价或已有日线价格；实际入账仍由用户反馈决定。可用 `trigger_operator="lte"` 表达低于阈值卖出，`"gte"` 表达突破买入；省略触发价表示本次直接建议，已有持仓仍可加仓。旧数量信号仍可读取，但新模板使用比例。

`context.store.get/set/delete` 提供跨阶段、跨交易日 KV。快测和回测仅在一次运行内存中保留，实盘按实例持久保存到 MariaDB；阶段成功时与建议原子提交，失败不提交，重试不会重复更新。状态支持 JSON 值和有限 Decimal，Decimal 保存为十进制字符串，读取后可用 `Decimal(value)` 恢复；总量限制 256 KiB。源码全局变量不能替代持久状态。

`context.securities(industry=...)` 查询已知的申万一级行业股票池，`security_info` 读取证券风险/行业快照，`financials` 读取可见财务历史，`valuation` 读取可见估值。历史分类或财报没有可见记录时不补造；ST 标记来自证券名称，未知值为 None。实盘盘中可用 `quotes(symbols)` 批量查询或 `current_price(symbol)` 单股查询，宿主只为请求的股票访问真实接口，同阶段缓存结果。

每次保存创建不可变版本。策略在 `python -I` 子进程运行，限制导入和危险内置函数，设置超时、输出上限并过滤敏感环境变量。这适合当前受限可信用户环境，不是强隔离的多租户沙箱。
“运行当前版本”是单交易日快速测试：后台 worker 按三个阶段运行并推进模拟组合，展示信号、输出、模拟组合和失败原因；不推进真实持仓、不发送通知。只读取该日及此前最多 5 个实际交易日内可见日线。用户可显式开启 Mock，重复首个可见价格补足技术窗口，结果标记补值次数；不补造财报，不改变正式回测/实盘的数据，不可用作实盘启动依据。默认不开启，数据不足仍明确返回。模拟盘中报价使用当日开收盘均值，包含收盘信息，仅为日线近似。单阶段标准输出上限 64 KiB，策略结果传输上限 8 MiB。

实盘和回测中的日线因子默认只看到当前交易日及此前 250 个交易日；若策略确需更长历史，可在源码顶层声明 `HISTORY_TRADING_DAYS = 500`，允许范围为 1–2500。保存后产生新的不可变策略版本。这个窗口限制每个决策日的可见历史，不限制回测的整体起止日期；快测始终固定为此前 5 日。盘前/盘中仍不得看到当日收盘数据。行情页缓存仅在单个任务内有效，按交易日整页读取，最多保留 12 页，按 LRU 淘汰；不需要 Redis，也不会在数据同步后跨任务留存旧页。
