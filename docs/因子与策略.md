# 因子与策略

## 因子

因子是平台代码内的只读方法，随 Easy Quant 发布，不由用户创建、编辑或单独版本化。因子目录展示说明、参数、输出结构、输出示例和调用示例。示例中的数值和日期仅用于说明返回结构；技术及统计因子的计算结果为 Python `Decimal`，数据不足时通过 `available: False` 与 `required`、`actual` 等字段说明原因。行情和基本面记录的字段会随数据集而不同，策略应先检查记录是否存在。

| 因子 | 当前能力 |
| --- | --- |
| `market.daily-bars` | 读取决策时点可见的日线 K 线 |
| `market.value` | 读取最新可见的估值与市值记录 |
| `technical.ma` | 移动平均线，`window=5` 即 5 日均线 |
| `technical.rsi` | 指定窗口 RSI |
| `technical.macd` | DIF、DEA 与 MACD 柱值 |
| `stat.expected-return` | 历史胜率和预期回报 |
| `fundamental.latest` | 指定基本面数据集的最新可见记录 |
| `fundamental.history` | 指定基本面数据集的可见历史序列 |

机器学习因子只能加载随应用发布且摘要匹配的权重，运行期不训练或上传模型。

## 策略契约

策略必须实现 `before_market(context, parameters)`、`on_market(context, parameters)` 和 `after_market(context, parameters)` 三个钩子。每个钩子返回信号列表；系统不提供旧策略协议兼容入口。信号至少包含 `symbol`、`action`、`quantity` 和 `reason`，盘中条件信号可带 `trigger_price`。

策略上下文提供股票池、当前持仓、盘中价格以及 `factor` 调用。盘前只看到此前已知数据；盘中通过当前报价判断触价；盘后可以读取当日收盘数据。页面提供“5 日均线选股”和“正预期示例”，两者与用户策略使用完全相同的保存、版本和运行机制。`ref/大数投资.聚宽回测.py` 只用于内部能力映射，不作为示例发布。

回测的 `context.position(symbol)` 读取该阶段开始时已模拟成交的持仓，现金通过 `context.data["cash"]` 的十进制字符串提供；盘前成交后，盘中和盘后会看到更新的模拟组合。策略上下文是独立副本，修改它不会改变引擎账户。快速测试没有组合推进；实盘以人工操作账本为准。

每次保存创建不可变版本。策略在 `python -I` 子进程运行，限制导入和危险内置函数，设置超时、输出上限并过滤敏感环境变量。这适合当前受限可信用户环境，不是强隔离的多租户沙箱。
“运行当前版本”是单交易日快速测试：用户指定交易日后，后台 worker 按盘前、盘中、盘后顺序运行，展示各阶段信号、标准输出和失败原因；不推进真实持仓、不发送通知。运行绑定保存的策略版本，只读取该日及此前最多 5 个实际交易日内已同步且在该时点可获知的日线。超出窗口的长周期因子可能返回数据不足；需要完整长期历史时应使用回测。单阶段标准输出上限为 64 KiB，策略结果传输有独立的 8 MiB 上限；大量合法信号不计入标准输出。

实盘和回测中的日线因子默认只看到当前交易日及此前 250 个交易日；若策略确需更长历史，可在源码顶层声明 `HISTORY_TRADING_DAYS = 500`，允许范围为 1–2500。保存后产生新的不可变策略版本。这个窗口限制每个决策日的可见历史，不限制回测的整体起止日期；快测始终固定为此前 5 日。盘前/盘中仍不得看到当日收盘数据。行情页缓存仅在单个任务内有效，按交易日整页读取，最多保留 12 页，按 LRU 淘汰；不需要 Redis，也不会在数据同步后跨任务留存旧页。
