## 使用与共同口径

```python
value = context.factor("return_21d", symbol=symbol)
alpha = context.factor("alpha101_3", symbol=symbol, symbols=["000001", "000002"])
bars = context.library("market.daily-bars", symbol=symbol)
```

因子即时返回 `available/value`，失败为 `available=False/reason`，缺失不补零，结果不持久化。本文列表各Key采用固定公式窗口，不覆盖窗口参数；window/period/fast等额外参数不被接受。原有technical.ma/rsi/macd仍按其各自接口定义执行。

- 所有运算使用Decimal；标准差和协方差采用总体定义（ddof=0）。参考页未给完整标准差自由度、EMA种子等约定，因此同源公式不意味着与付费服务数值逐位一致。
- 输入为平台日线的同一价格口径，不自动拼接不同复权数据；收益为相邻收盘价比减1。公司行为是否复权由输入数据决定。成交量为股、成交额为元，VWAP=成交额/成交量；缺成交额不以典型价代替。
- 截面项必须显式传symbols（目标必须在内），最多500只，结果代表该股票池而非全市场。每日按同交易日有效样本排名，平均并列秩除以样本数；缺失不填零，不把Ts_Rank当截面Rank。历史股票池由调用者显式确定，不宣称消除了股票池选择的幸存者偏差。
- 时间窗口在显式股票池可见交易日网格上推进；某股票缺一日时窗口保留缺口，不跨缺日压缩。所有记录先按available_at过滤。Alpha101的ArgMax从窗口最早日算1，取首个并列最大位置；Decay_Linear新数据权重大。
- 指数使用sh000001、sh000300独立代码空间，股票与指数必须具有相同的窗口交易日；缺失日期不填充、不按位置错配。回归包含截距；sigma为同一窗口回归残差的总体标准差；beta_consistency为beta乘残差的标准差。
- RSI采用Wilder递归平滑（alpha=1/14，首个变化为种子，adjust=False）。MACD/DEA/DIF的EMA首个收盘价为种子；使用当前预热窗口内的全部输入，所以声明不同HISTORY_TRADING_DAYS可能改变这些递归因子的结果。原有technical.rsi仍是简单均值口径，不能当作本表rsi的别名。
- RSRS遵循参考页Low~High的方向，18日回归、200个斜率标准化，需要217条。days_beyond对每日21日滚动Z再计21日超界差，需要41条。days_down_up连续段截至相等收盘价终止，历史被窗口截断时仅统计窗口内连续段。
- price_dist默认不做平滑，价格按1/10/100缩放后距下一个整数，整数点返回1。规模因子使用截至决策时点最新可见市值快照（元），除以百万后取负自然对数；不把旧市值推算为今日市值。nl_size显式股票池至少3个完整样本，截面回归含截距。

回测、快测和实盘均传递完整日线字段；回测预热读取定义的实际窗口，1320日回归预热1321条而非截到250。快测最多加载含所选日在内 7 日，长窗口指标可用默认 Mock 补足，不能据此验证完整历史口径。动态因子Key应通过HISTORY_TRADING_DAYS显式声明窗口；无法静态分析时仅提供默认250日，不足会明确失败。该数据链调整不改K线表、不要求删除或重新拉取已有K线；历史amount缺失的条目仅会令依赖成交额的因子不可用。
