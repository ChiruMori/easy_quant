# 因子计算逻辑与结果含义

本文由平台当前因子元数据导出，与因子目录使用相同说明。
更新命令：`uv run --project backend python backend/tools/export_factor_docs.py`。

## Alpha101 算子约定

C/O/H/L/V分别为收盘/开盘/最高/最低/成交量；W为成交额/成交量；ret=C/前收盘-1，ADV20=20日均量。R为指定股票池同日平均并列秩/N，TR为当前值在自身窗口内的平均并列秩/N；两者不可互换。Delta(X,n)=X-Delay(X,n)，Delay滞后n个网格交易日；Sum/Mean/Min/Max/Std为滚动窗口运算，Std和Cov使用总体定义。Corr为相关系数，Sign为符号，Abs为绝对值，Where为条件选择。ArgMax从窗口最早一天算1，取首个最大值位置；DecayLinear给新数据更大权重。这些解释描述公式的机械含义，不构成买卖建议；高分不等于未来收益更高。

数据可见性、缺失处理、输入口径与股票池范围见[对标因子](对标因子.md)。

## technical.ma：移动平均线（含 5 日均线）

计算逻辑：最近window个收盘价求算术均值，window=5即5日均线。结果含义：描述近期平均价格水平，用于平滑价格；不直接规定买卖方向。

## stat.expected-return：历史预期回报

计算逻辑：相邻收盘价比减1得到日收益，求平均值作为expected_return；正收益日数除以收益样本数作为win_rate。结果含义：二者只描述输入历史样本，不是未来收益或获胜概率保证。

## technical.rsi：相对强弱指标 RSI

计算逻辑：最近window个价差分别取上涨和下跌绝对值的简单均值，RS=平均上涨/平均下跌，RSI=100-100/(1+RS)；平均下跌为零时返回100。结果含义：较高表示近期上涨价差相对更强；全平也按当前实现返回100。此接口不是Wilder递归平滑的rsi。

## technical.macd：指数平滑异同移动平均线 MACD

计算逻辑：快慢EMA之差为DIF，DIF的信号EMA为DEA，柱值=2*(DIF-DEA)，EMA从窗口首值递推。结果含义：DIF正表示快线高于慢线，柱值正表示DIF高于DEA；数值使用价格单位，不代表收益率。

## alpha101_1：下跌波动与价格极值位置

下跌波动与价格极值位置。

公式：

```text
R(ArgMax(Where(ret<0, Std(ret,20), C)^2,5))-0.5
```

计算逻辑：下跌日用20日收益波动替换收盘价，其他日用收盘价；平方后找最近5日最大值的位置，再截面排名并减0.5。

结果含义：值较高表示替换后序列的最大值出现得相对较晚；它混合了价格与下跌波动，并非单纯的涨跌幅。

## alpha101_2：量变与日内涨跌的反向相关

量变与日内涨跌的反向相关。

公式：

```text
-Corr(R(Delta(Log(V),2)), R((C-O)/O),6)
```

计算逻辑：分别对两日对数成交量变化和当日开收盘收益做截面排名，再求最近6日相关系数并取负。

结果含义：值较高意味着量变排名与日内涨跌排名更倾向反向变化；值较低意味着二者更同向。

## alpha101_3：开盘价格与成交量排名的反向相关

开盘价格与成交量排名的反向相关。

公式：

```text
-Corr(R(O),R(V),10)
```

计算逻辑：每日在指定股票池中分别排列开盘价、成交量，再计算两条排名序列的10日相关系数并取负。

结果含义：值较高表示价格排名和成交量排名在这段时间更反向；比较的是池内相对位置，并非单只股票的价格与成交量绝对值。

## alpha101_4：最低价相对位置的短期反转

最低价相对位置的短期反转。

公式：

```text
-TR(R(L),9)
```

计算逻辑：先求每天最低价的截面排名，再把今日排名放入该股票最近9日排名序列中比较，最后取负。

结果含义：更接近零表示今日最低价的池内排名处于自身近期低位；更负表示处于近期高位。

## alpha101_5：开盘偏离均价与收盘偏离均价组合

开盘偏离均价与收盘偏离均价组合。

公式：

```text
R(O-Mean(W,10)) * -Abs(R(C-W))
```

计算逻辑：对开盘价减10日VWAP均值、收盘价减当日VWAP分别做截面排名，再将前者乘以后者绝对值的负数。

结果含义：两种偏离的排名同时较高时结果更负；数值同时受隔夜开盘位置与当日收盘相对成交均价的位置影响。

## alpha101_6：开盘价与成交量的反向相关

开盘价与成交量的反向相关。

公式：

```text
-Corr(O,V,10)
```

计算逻辑：直接使用该股票最近10日开盘价与成交量计算相关系数，再取负，不做截面排名。

结果含义：正值表示开盘价与成交量近期负相关，负值表示正相关；不同于第3项的排名相关。

## alpha101_7：放量条件下的价格变化反转

放量条件下的价格变化反转。

公式：

```text
Where(V>ADV20, -TR(Abs(Delta(C,7)),60)*Sign(Delta(C,7)), -1)
```

计算逻辑：当日成交量超过20日均量时，比较7日价格变化绝对值在60日内的位置，再乘以变化方向的负号；否则固定返回-1。

结果含义：放量且近期跌幅较突出时为较大的正值，放量且涨幅突出时为较小的负值；未放量的-1只是分支固定值。

## alpha101_8：开盘价与收益累计乘积的变化

开盘价与收益累计乘积的变化。

公式：

```text
-R(Delta(Sum(O,5)*Sum(ret,5),10))
```

计算逻辑：将5日开盘价之和与5日日收益之和相乘，计算该乘积相对10日前的变化，再截面排名并取负。

结果含义：更接近零表示该复合量的增幅排名较低，更负表示增幅排名较高；它不是5日累计收益率本身。

## alpha101_9：连续同向时保留、混合走势时反转

连续同向时保留、混合走势时反转。

公式：

```text
Where(Min(Delta(C,1),5)>0 or Max(Delta(C,1),5)<0, Delta(C,1), -Delta(C,1))
```

计算逻辑：检查最近5个单日收盘价差：若全部严格上涨或全部严格下跌，保留今日价差；否则取今日价差的相反数。

结果含义：连续单向走势走延续分支，方向混合或出现零价差时走反转分支；结果单位是价格，不是收益率。

## alpha101_10：四日走势条件切换后的截面排名

四日走势条件切换后的截面排名。

公式：

```text
R(Where(Min(Delta(C,1),4)>0 or Max(Delta(C,1),4)<0, Delta(C,1), -Delta(C,1)))
```

计算逻辑：以最近4个单日价差判断是否连续同向；同向保留今日价差，否则取反，最后在股票池中排名。

结果含义：值较高表示条件切换后的价差相对较大；与第9项相比，窗口更短且结果经过截面排名。

## alpha101_11：均价偏离极值与量变组合

均价偏离极值与量变组合。

公式：

```text
(R(Max(W-C,3))+R(Min(W-C,3)))*R(Delta(V,3))
```

计算逻辑：取VWAP减收盘价最近3日的最大和最小值，分别截面排名并相加，再乘以3日成交量变化的排名。

结果含义：值较高表示收盘低于成交均价的偏离位置和成交量增长排名的组合较强；不能仅凭结果判断是上涨还是下跌。

## alpha101_12：成交量变化方向与价格变化反转

成交量变化方向与价格变化反转。

公式：

```text
Sign(Delta(V,1)) * -Delta(C,1)
```

计算逻辑：只取成交量较昨日增加还是减少的方向，乘以今日收盘价差的负值。

结果含义：量增价跌或量减价涨时为正，量增价涨或量减价跌时为负；成交量不变时为零。

## alpha101_13：收盘价排名与成交量排名的协方差

收盘价排名与成交量排名的协方差。

公式：

```text
-R(Cov(R(C),R(V),5))
```

计算逻辑：先对每日收盘价、成交量做截面排名，再计算两条排名序列的5日协方差，对协方差排名后取负。

结果含义：更接近零表示量价排名的共同变动较弱或更反向；使用协方差而非相关系数，仍受排名波动幅度影响。

## alpha101_14：收益变化排名与开盘量相关组合

收益变化排名与开盘量相关组合。

公式：

```text
-R(Delta(ret,3))*Corr(O,V,10)
```

计算逻辑：对今日收益率相对3日前的变化做截面排名，再乘以10日开盘价与成交量相关系数的负值。

结果含义：结果符号由量价相关的反向符号决定，幅度同时受收益变化的相对排名影响；不是单独的三日收益率。

## alpha101_15：高价与成交量排名相关的短期累积

高价与成交量排名相关的短期累积。

公式：

```text
-Sum(R(Corr(R(H),R(V),3)),3)
```

计算逻辑：每日先排列最高价和成交量，求3日排名相关，再对相关系数做截面排名，累计最近3日的排名后取负。

结果含义：更负表示短期内高价排名与成交量排名的相关性排名持续较高；更接近零表示持续较低。

## alpha101_16：最高价排名与成交量排名的协方差

最高价排名与成交量排名的协方差。

公式：

```text
-R(Cov(R(H),R(V),5))
```

计算逻辑：对每日最高价和成交量分别截面排名，求5日协方差，再对协方差截面排名并取负。

结果含义：更接近零表示最高价与成交量相对排名的共同变动排名较低；与第13项的区别是使用最高价。

## alpha101_17：价格位置、价差变化与相对成交量组合

价格位置、价差变化与相对成交量组合。

公式：

```text
-R(TR(C,10))*R(Delta(Delta(C,1),1))*R(TR(V/ADV20,5))
```

计算逻辑：将收盘价在自身10日内的位置、单日价差的变化、相对20日均量在自身5日内的位置分别截面排名，再相乘并取负。

结果含义：三项相对排名同时较高时结果更负；它把价格位置、价格变化的加速度和相对放量程度结合起来。

## alpha101_18：日内价差波动与开收盘相关组合

日内价差波动与开收盘相关组合。

公式：

```text
-R(Std(Abs(C-O),5)+(C-O)+Corr(C,O,10))
```

计算逻辑：将5日日内价差绝对值的标准差、今日开收盘价差、10日开收盘相关系数相加，再截面排名并取负。

结果含义：更负表示这个复合分数排名较高；公式直接混合价格量纲和相关系数，不能将其解释为标准化风险值。

## alpha101_19：周度价格反转与量价相关惩罚

周度价格反转与量价相关惩罚。

公式：

```text
A=-Sign((C-Delay(C,7))+Delta(C,7))*(1+R(1+Sum(ret,250))); B=R(Corr(R(W-C),R(V),12)*R(Corr(R(C),R(ADV20),12))); result=A-B^2
```

计算逻辑：先按7日价格变化方向取反，并用250日日收益之和的排名放大；再计算两种12日排名相关的组合排名，减去其平方。

结果含义：第一部分给近期下跌正号、上涨负号，第二部分始终非正；二者合成后不能只按7日涨跌判断结果。这里遵循本平台参考列表的复合公式。

## alpha101_20：开盘相对昨日价格区间的位置

开盘相对昨日价格区间的位置。

公式：

```text
-R(O-Delay(H,1))*R(O-Delay(C,1))*R(O-Delay(L,1))
```

计算逻辑：分别计算今日开盘相对昨日最高、收盘、最低价的差，做截面排名，将三项排名相乘并取负。

结果含义：开盘相对昨日价格区间的三种偏离排名同时较高时更负；它描述相对跳空位置，而不是实际跳空百分比。

## alpha101_22：高价量相关变化与价格波动组合

高价量相关变化与价格波动组合。

公式：

```text
-Delta(Corr(H,V,5),5)*R(Std(C,20))
```

计算逻辑：计算最高价与成交量的5日相关系数相对5日前的变化，取负后乘以20日收盘价波动的截面排名。

结果含义：量价相关减弱时为正、增强时为负；价格波动排名越高，对相关变化的放大越强。

## alpha101_23：高价高于近期均值时的高价变化反转

高价高于近期均值时的高价变化反转。

公式：

```text
Where(H>Mean(H,20), -Delta(H,2), 0)
```

计算逻辑：当今日最高价超过20日最高价均值时，返回最高价相对两日前变化的负值；否则返回零。

结果含义：进入条件分支后，高价较两日前上升为负、下降为正；零也可能只是未满足条件，不代表市场没有波动。

## alpha101_25：收益、均量、均价和收盘位置组合

收益、均量、均价和收盘位置组合。

公式：

```text
R(-ret*ADV20*W*(H-C))
```

计算逻辑：将当日收益的负值、20日均量、当日VWAP及最高价减收盘价相乘，再截面排名。

结果含义：其他项非负时，下跌且收盘远离最高价的组合分数可较高；大成交量和高价格也会放大原始分数。

## alpha101_33：开收盘相对涨幅排名

开收盘相对涨幅排名。

公式：

```text
R(O/C-1)
```

计算逻辑：用开盘价除以收盘价再减1，在指定股票池中排名。

结果含义：值较高对应日内下跌相对更明显或上涨更弱；注意分母是收盘价，与(C-O)/O的常规日内收益不同。

## alpha101_34：短长波动比与单日价差的反转排名

短长波动比与单日价差的反转排名。

公式：

```text
R(2-R(Std(ret,2)/Std(ret,5))-R(Delta(C,1)))
```

计算逻辑：分别排列2日与5日收益波动之比、今日收盘价差；用2减去两项排名，再对结果截面排名。

结果含义：短期波动比排名较低、今日价差排名较低的股票，最终分数倾向更高；五日波动为零时不可计算。

## alpha101_41：日内价格区间几何中心与成交均价偏离

日内价格区间几何中心与成交均价偏离。

公式：

```text
Sqrt(H*L)-W
```

计算逻辑：取当日最高价与最低价的几何平均，减去当日VWAP。

结果含义：正值表示几何价格中心高于成交均价，负值表示低于；结果单位是价格，不作截面排名。

## alpha101_52：近期低点变化、长短收益差和量位置组合

近期低点变化、长短收益差和量位置组合。

公式：

```text
(Delay(Min(L,5),5)-Min(L,5))*R((Sum(ret,240)-Sum(ret,20))/220)*TR(V,5)
```

计算逻辑：比较当前与5日前的滚动5日最低价，乘以剔除最近20日后的220日日收益均值排名，再乘以今日成交量的5日时间序列排名。

结果含义：近期滚动低点下移时第一项为正，上移时为负；长期收益相对位置和近期量位置共同调节幅度。

## alpha101_53：收盘在日内区间中位置的变化反转

收盘在日内区间中位置的变化反转。

公式：

```text
-Delta(((C-L)-(H-C))/(C-L),9)
```

计算逻辑：先计算收盘相对日内高低点的位置比率，再取该比率相对9日前变化的负值。

结果含义：正值表示这个位置比率下降，负值表示上升；C等于L时分母为零，不能将结果当作零。

## alpha101_54：日内收盘位置与开收盘比的非线性组合

日内收盘位置与开收盘比的非线性组合。

公式：

```text
-((L-C)*O^5)/((L-H)*C^5)
```

计算逻辑：将收盘相对最低价的位置和开盘/收盘比的五次幂结合；等价于-(C-L)/(H-L)*(O/C)^5。

结果含义：正常正价格区间下结果非正；收盘越靠近最高价、开盘/收盘比越大时更负。高低价相等或收盘为零时不可计算。

## alpha101_57：收盘偏离均价相对价格峰值时点的比例

收盘偏离均价相对价格峰值时点的比例。

公式：

```text
-(C-W)/DecayLinear(R(ArgMax(C,30)),2)
```

计算逻辑：找到30日收盘最高值首次出现的位置并做截面排名，对这个排名做2日线性衰减平均，再以收盘减VWAP的负值除以它。

结果含义：收盘低于VWAP时为正，高于时为负；分母较小会放大偏离，因此需要同时理解价格峰值时点排名。

## alpha101_101：日内实体相对价格振幅

日内实体相对价格振幅。

公式：

```text
(C-O)/(H-L+0.001)
```

计算逻辑：以当日收盘减开盘的价差，除以最高减最低的振幅加0.001。

结果含义：正值表示收盘高于开盘，负值相反；绝对值越大，开收盘实体相对当日振幅越大。0.001是价格单位常数。
