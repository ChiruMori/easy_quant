# 平台库函数与因子

`context.library(key, **parameters)` 直接读取平台维护的数据；`context.factor(key, **parameters)` 每次计算派生结果，不保存因子结果。因子目录包含平台基础计算与[对标因子](对标因子.md)，不列原始数据读取。

库函数包括 `market.daily-bars`、`market.value`、`fundamental.latest` 和 `fundamental.history`。前两者传 symbol；基本面另传 dataset。旧策略通过 factor 读取这些数据的入口已移除，统一改为 library；计算因子的 factor 调用不变。无需删除或重新同步K线。锁定策略版本应复制为新草稿后修改，旧回测与实盘可按业务需要清理，不是升级前提。

```python
bars = context.library("market.daily-bars", symbol=symbol)
ma = context.factor("technical.ma", symbol=symbol, window=30)
reports = context.library("fundamental.history", symbol=symbol, dataset="financial-indicators")
```

回测在执行前按交易日窗口批量加载预热历史，运行期增量推进数据快照；调用因子不查数据库。快照按数据集和标的归一化一次，同一上下文后续调用复用原始输入，每次重新计算因子。返回记录使用副本，不能污染后续计算。所有数据仍按 available_at 过滤；快照预热不代表未来数据可见。动态窗口应显式声明 HISTORY_TRADING_DAYS（1–2500）；EMA 和统计因子沿用完整输入窗口口径。

数据读取实现与底层上下文位于 backend/src/easy_quant/platform_library；该层不导入 factors。K 线继续由现有行情存储、数据同步任务与适配器独立维护，不要求所有库函数共享存储、获取流程或任务。新增平台能力按实际需要单独实现边界，不能反向调用因子。

因子实现位于 factors，FactorDefinition 声明默认参数、整数参数校验及数据集依赖；新增计算注册定义及纯计算方法，数据依赖提取自动读取定义。因子无用户版本，随应用发布；默认参数与算法修改仍须验证时间一致性及离线测试。当前未新增机器学习因子或模型加载能力。

## 调用差异

| 原调用 | 当前调用 |
| --- | --- |
| `context.factor("market.daily-bars", symbol=symbol)` | `context.library("market.daily-bars", symbol=symbol)` |
| `context.factor("market.value", symbol=symbol)` | `context.library("market.value", symbol=symbol)` |
| `context.factor("fundamental.latest", symbol=symbol, dataset=dataset)` | `context.library("fundamental.latest", symbol=symbol, dataset=dataset)` |
| `context.factor("fundamental.history", symbol=symbol, dataset=dataset)` | `context.library("fundamental.history", symbol=symbol, dataset=dataset)` |

代码、调用入口和运行快照发生变化，K线表、数据身份及同步任务保持原有契约；本次无数据清空或重建迁移。
