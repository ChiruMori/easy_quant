# 当前限制

- Easy Quant 只支持单机、少量可信用户，不提供分布式部署、高可用或水平扩缩容。
- 行情历史最细为日线。盘中监控只使用临时当前报价，不保存分钟或逐笔数据。
- 系统只提供建议和人工操作账本，不连接券商或交易所，不自动下单。
- 数据来源成功即接受，不交叉验证不同来源的一致性或正确性；公开接口变化、限流和数据错误仍需管理员处理。
- 数据获取和回测创建 API 在当前单机版本中同步执行，超大批次应拆分股票和日期范围。
- 策略试运行加载全部已导入日线，实盘上下文加载截止日的全市场历史，回测按日期范围加载全市场日线。全市场多年数据下内存开销较大；当前全量数据验收覆盖下载、入库和覆盖查询，尚未完成该规模的真实策略/回测验收。
- 全市场通达信历史通过 CLI 导入，浏览器 CSV 上传仍适合小批量数据；CLI 不提供页面进度或定时下载任务。
- 通达信完整包导入的是不复权日线，不包含复权因子或可靠的退市/更名映射。同一股票不能同时存储多个复权口径，已有不复权历史时页面前复权补齐会拒绝写入，需使用官方包 CLI 更新。
- 实际操作的资金/持仓校验发生在持久化写入之后；操作、账本和建议状态分次提交，资金不足等失败请求仍可能留下已写入状态。
- 动态策略子进程适合受邀可信用户，不构成可运行任意不可信代码的强安全沙箱。
- 基本面数据的字段随来源保留，策略应通过因子并按数据集文档读取；来源字段变化可能需要适配器更新。
