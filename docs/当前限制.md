# 当前限制

- Easy Quant 只支持单机、少量可信用户，不提供分布式部署、高可用或水平扩缩容。
- 行情历史最细为日线。实盘每天统一时刻执行一次盘中分析，按策略请求读取临时当前报价，不保存分钟或逐笔数据。
- 系统只提供建议和人工操作账本，不连接券商或交易所，不自动下单。
- 数据来源成功即接受，不交叉验证不同来源的一致性或正确性；公开接口变化、限流和数据错误仍需管理员处理。
- 数据同步、策略快速测试和回测提交使用持久后台任务，需要运行 worker；任务排队和失败可在页面查询。
- 快测只读取所选日及此前 5 个交易日；实盘与回测的历史窗口默认 250 个交易日，源码可声明 1–2500 日。回测按月读取、逐日推进和流式保存快照，交易及输出结果仍随运行区间增长；全市场多年回测的实际耗时与资源目标仍需真实数据验收。
- 回测读取起始日前已存储的窗口历史预热因子，数据不足仍如实报错。快测可显式启用技术指标历史补值，结果会披露。模拟组合从初始现金、空仓开始，每个钩子看到阶段开始快照；比例信号在同一钩子内预留预算。模拟盘中价为当日开收盘均值，使用收盘信息，不能代表真实盘中收益。
- 全市场通达信历史通过 CLI 导入，浏览器 CSV 上传仍适合小批量数据；全量 CLI 不提供页面进度。每日增量可用 CLI 或管理员创建的“通达信 A 股盘后增量”计划执行，需运行 worker。
- 通达信完整包和每日增量均为不复权日线，不包含复权因子或可靠的退市/更名映射。同一股票不能同时存储多个复权口径；页面补齐会沿用已知的历史口径，`unknown` 或混杂口径仍须先核实和修正数据。官方增量缺包保留待发布，单次补数最多 90 天；新证券只从首个已下载增量日开始，旧历史需再导入全量包。
- 停牌标记由管理员根据公告核实后维护，证券列表来源本身不提供可靠的停复牌事件。日线来源可能延迟，返回的最新日期早于请求结束日时只能提示核实，不能自动认定停牌或生成不存在的 K 线。
- 退市状态来自最近一次完整证券清单的差集或来源显式状态，没有精确退市日期。新建的历史回测按当前退市状态排除股票，因此历史选股结果存在幸存者偏差；回测记录会保存当次排除的代码，历史记录不会追溯修改。
- 新人工操作在校验后原子提交并可安全重试；此前可能已写入的无效账本不会自动修复。旧操作没有完整请求身份，旧键重放只提示核验现存状态。
- 实盘账本只以初始现金为基线，非零初始持仓尚未纳入不可变重建口径；成交时间目前取服务器时钟，页面没有历史成交时间和备注录入。
- 实盘核心状态仍复用持久 JSON 文档；人工反馈使用短事务串行处理。建议、KV、阶段完成标记与通知 outbox 同事务提交，通知失败在下一次分析恢复投递。
- 动态策略子进程适合受邀可信用户，不构成可运行任意不可信代码的强安全沙箱。
- 行业、ST 和估值为采集时点快照；未采集时的历史状态不会倒填。财报公告时间未知时仅从采集时刻可见，因此历史基本面可能不足；正式回测和实盘不补造这些数据。来源字段变化可能需要适配器更新。
