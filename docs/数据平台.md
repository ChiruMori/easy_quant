# 数据平台

## 数据集与来源

平台当前管理沪深京证券列表、交易日历、日线、估值与市值、股票质押率和财务指标。公开日线接口提供前复权数据；通达信官方完整归档通过管理员 CLI 导入不复权历史。日线、证券列表和盘中报价可通过 AKShare 或东方财富获取；其他数据集按页面显示的已启用来源获取。管理员只控制来源启停，系统每次随机选择起始来源，在来源内有限重试，失败后遍历其他来源，首个成功即停止，不比较多来源结果。

每个来源的成功原始响应先按“来源 + 语义请求”单独 gzip 缓存，并保存摘要、抓取时间和失效时间。缓存不可从页面查看。重复规范化记录会覆盖旧记录并返回覆盖数量。

## 覆盖和时效

股票覆盖表通过数据库聚合展示最早日期、最新日期和记录数：十年以上为“完全同步”，三至十年为“部分同步”，不足三年为“数据不足”，无记录为“未同步”。此标签按历史跨度划分，不表示期间每个交易日都无缺失，也不表示所有退市证券都已涵盖。
列表按每页 50 只股票请求，支持名称、代码搜索、上述四种同步状态筛选及输入页码直接跳转。前后翻页使用股票代码游标；无状态筛选时，直接跳页只在股票代码查询上定位，再读取目标页详情及日线覆盖。状态筛选只聚合日线首末日期，一次读取匹配的代码并在服务端定位页码；完整记录仍只读取目标页。点击股票可查看证券资料和已有日线 K 线；默认取最近 180 条，指定日期范围时最多返回最近 1,000 条。手动同步创建持久后台任务，页面可看到任务状态与来源尝试。

“已更新”只要求存在上一交易日的 K 线。即使今日是交易日且已经收盘，也仍按上一交易日判断。已有至少三个月历史数据但最新日期早于上一交易日时显示“已过时”。管理员可补齐到上一交易日；交易日收盘后还可选择补齐到今日。每日更新任务始终拉取上一交易日，由下一次任务补入今日收盘数据。

## 导入与时间语义

日线 CSV 必须包含 `symbol,trading_day,open,high,low,close,volume`。估值、质押、财务、行业和证券资料 CSV 至少包含 `symbol,available_at`，其中 `available_at` 必须是带时区的 ISO 时间，其余列原样保存供因子读取。导入先预检，确认后才写入。

日线和资金计算使用 `Decimal`。规范化数据携带 `available_at`，策略和回测只接收决策时点已经可见的记录。自动化测试使用 fake 与固定响应，不访问第三方网络或真实数据库。

通达信二进制日线的价格单位为分，导入后为元；成交量为股，成交额为元并按四位小数四舍五入。可获知时间固定为交易日 15:00 Asia/Shanghai。每条记录保存 `source=tdx-official`、`adjustment=none` 与归档 SHA256。已有证券名称保留，新证券无名称时只保存代码、交易所和未知状态。

当前日线主键为股票和交易日，同一股票只容纳一种复权口径。已有不复权记录时，页面的前复权补齐及未声明口径的 CSV 导入会拒绝写入，避免混用；更新通达信历史可运行 `pnpm data:tdx:update` 或创建“通达信 A 股盘后增量”定时任务。每日 COD/MD1 包完整预检后按日期事务提交，保留缺日状态并核验最近七日来源修订；官方休市日历只用于此更新流程。详细命令、恢复及边界见[通达信历史数据](通达信历史数据.md)。
