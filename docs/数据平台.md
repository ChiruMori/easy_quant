# 数据平台

## 数据集与来源

平台当前管理沪深京证券列表、交易日历、日线、估值与市值、股票质押率和财务指标。公开日线接口按已有历史口径获取不复权或前复权数据；无历史日线时默认前复权。通达信官方完整归档通过管理员 CLI 导入不复权历史。日线来源包括 AKShare 的东方财富接口、东方财富直连接口和 AKShare 的腾讯行情接口；腾讯行情与前两者的上游独立。证券列表和盘中报价仍按页面显示的来源获取。管理员控制来源启停，系统随机选择起始来源，在来源内有限重试，失败后遍历其他来源，首个成功即停止，不比较多来源结果。已有环境启动时自动加入启用的腾讯行情来源。

每个来源的成功原始响应先按“来源 + 语义请求”单独 gzip 缓存，并保存摘要、抓取时间和失效时间。缓存不可从页面查看。重复规范化记录会覆盖旧记录并返回覆盖数量。

日线写入按最多 500 行一批查询已有复合主键并批量 upsert；交易日历去重后批量保存，不对每根 K 线 get/merge。需要精确条数的页面仍按所选标的统计；回测和盘后同步只查询首末日期，使用 MIN/MAX 端点索引路径，不为无需使用的 COUNT 扫描全市场日线。

## 覆盖和时效

股票覆盖表通过数据库聚合展示最早日期、最新日期和记录数：在市股票最新日期早于最近可发布交易日时优先显示“数据落后”；达到该日期后，历史跨度十年以上为“完全同步”，三至十年为“部分同步”，不足三年为“数据不足”，无记录为“未同步”。状态筛选与分页使用相同目标日期。这些标签不表示期间每个交易日都无缺失，也不表示所有退市证券都已涵盖。

覆盖表上方显示当前应更新至的日期。交易日历超出已知范围时按工作日估算，并明确提示刷新日历核实，避免日历与行情一起落后而误报同步；估算无法识别未知节假日。页面提供“整体同步（推荐）”入口，跳转定时任务页后可立即执行“盘后全量数据同步”并检查定时计划启用状态；打开页面或点击导航不会创建任务。
列表按每页 50 只股票请求，支持名称、代码搜索、同步状态筛选及输入页码直接跳转。前后翻页使用股票代码游标；无状态筛选时，直接跳页只在股票代码查询上定位，再读取目标页详情及日线覆盖。状态筛选只聚合日线首末日期，一次读取匹配的代码并在服务端定位页码；完整记录仍只读取目标页。点击股票可查看证券资料及日、周、月 K 线，按 A 股习惯红涨绿跌，支持拖动、滚轮缩放与滑块；悬浮数据提示使用中文字段，周/月 OHLC 由日线聚合。默认取最近 180 条日线，指定日期范围时最多返回最近 1,000 条日线。列表的“更新至”按钮创建持久后台任务后持续显示排队、运行及结果；失败时可展开来源尝试明细。来源返回的最后 K 线早于请求结束日时，任务明确报告该日期以及可能停牌或来源延迟，不补造行情。

新鲜度以最近可发布交易日判断。`EASY_QUANT_DAILY_DATA_PUBLISH_TIME` 默认 22:00，此前只要求上一交易日日线；当天尚未发布不显示过期或更新按钮。发布时刻之后才以当天为目标。若同步已确认来源未返回目标日期，则显示“来源尚未发布新数据”，隐藏该目标的无效更新按钮；新交易日重新计算。不会把缺少当天数据误认成停牌。

管理员可创建“盘后全量数据同步” Cron 任务，例如 `0 22 * * 1-5`、Asia/Shanghai。任务先刷新交易日历、证券清单及停复牌状态，再为日线、估值、质押、财务和申万一级行业创建持久分批任务；日线批次跳过已停牌股票。结果在后台任务和数据获取页面查询。失败批次可在数据获取页面用相同范围重新提交，不需要重跑成功范围。盘前不自动同步，读取昨晚已保存数据；仅实盘盘中按策略请求股票代码获取临时报价，不落分钟行情。

申万行业使用实际采集时间的分类快照，保留分类、级别、行业代码和名称，不能据此重建采集前的历史归属。证券风险快照随证券清单刷新，ST 根据名称标记，停复牌在盘后自动核实更新，管理员入口仅供异常修正。财务提供 report_period、publication_time_known、roe（百分数）及可获取的利润字段；字段缺失为 None。公告日期存在时采用当日结束作为保守可见时间，无公告日期则采用实际采集时间，不能用报告期倒填可获知时间。估值也以采集时间可见。

数据覆盖页的“刷新停复牌状态”按最近可发布交易日创建异步任务，持续显示排队、运行和结果；完成后自动刷新覆盖列表。`trading-status` 数据集从东方财富停复牌接口批量分页读取，以明确开始、截止时间及整日停牌时段确认状态，保存来源、采集时点和停牌区间。字段及日期参数参照 [AKShare 官方适配器](https://github.com/akfamily/akshare/blob/main/akshare/stock_feature/stock_tfp_em.py)。证券状态批量写入；日线覆盖只读取索引首末端点，不逐只拉取历史、不扫描明细计数。对原先停牌、当天未在完整停牌名单中确认停牌的少量候选股票，自动通过已启用的日线来源请求目标交易日；只有日期精确匹配、成交量及收盘价为有限正数的真实成交记录才确认复牌。复牌证据、变更前后状态和来源保存为风险状态快照，恢复在市后自动纳入同一轮盘后日线批次。确认请求为不复权，只作成交证据，不混写已有日线的复权口径。无效或不完整响应使任务失败并保留状态；空名单、未出现在名单中、来源未发布行情及预计复牌日都不会直接触发复牌；证据不足或确认来源失败时保留原状态，结果报告待确认股票及来源尝试，下次盘后自动重试，不要求管理员日常逐只核对。仅更新最近交易日状态，拒绝历史或未来任务覆盖当前状态。已有同日或更新日线时不采用旧停牌证据。

管理员也可在股票详情填写交易所公告依据并标记“已停牌”。停牌行仅显示停牌，不显示数据落后、过期、等待发布及日线更新按钮；直接提交日线同步也会跳过这些股票，但历史 K 线保留。证券清单接受明确的停牌状态，普通在市清单不会将停牌重置为在市；仍在清单中的停牌股票不会被误判为退市。复牌由盘后流程自动确认并恢复，无需管理员逐只操作；不会仅凭预计复牌日期恢复。停牌股票不参与快测和实盘当前信号，历史回测仍读取停牌前真实日线，不要求停牌股票覆盖区间端点，也不补造停牌期间行情。

完整刷新证券基础信息后，不再出现在清单中的既有股票标记为“已退市”；局部刷新和空清单不会批量更改退市状态。退市股票保留历史行情和覆盖统计，页面不显示数据新鲜度标签及补齐按钮，可通过“已退市”筛选。快速测试、回测和实盘运行均排除这些股票的行情、基础数据及信号；已有回测记录保持原样。

## 导入与时间语义

日线 CSV 必须包含 `symbol,trading_day,open,high,low,close,volume`。估值、质押、财务、行业和证券资料 CSV 至少包含 `symbol,available_at`，其中 `available_at` 必须是带时区的 ISO 时间，其余列原样保存供因子读取。导入先预检，确认后才写入。

日线和资金计算使用 `Decimal`。规范化数据携带 `available_at`，策略和回测只接收决策时点已经可见的记录。自动化测试使用 fake 与固定响应，不访问第三方网络或真实数据库。

通达信二进制日线的价格单位为分，导入后为元；成交量为股，成交额为元并按四位小数四舍五入。可获知时间固定为交易日 15:00 Asia/Shanghai。每条记录保存 `source=tdx-official`、`adjustment=none` 与归档 SHA256。已有证券名称保留，新证券无名称时只保存代码、交易所和未知状态。

当前日线主键为股票和交易日，同一股票只容纳一种复权口径。页面补齐先读取该股票现有口径：不复权历史请求不复权，前复权历史请求前复权；原始缓存也按口径隔离。历史口径为 `unknown` 或已有多种口径时无法安全判断，任务会在抓取前失败且不覆盖历史数据。未声明口径的 CSV 导入仍会因口径冲突而拒绝写入。更新通达信历史还可运行 `pnpm data:tdx:update` 或创建“通达信 A 股盘后增量”定时任务。每日 COD/MD1 包完整预检后按日期事务提交，保留缺日状态并核验最近七日来源修订；官方休市日历只用于此更新流程。详细命令、恢复及边界见[通达信历史数据](通达信历史数据.md)。

## 日线存储

应用只使用共享血缘日线结构；当前 schema 为 0011，新空库运行 `pnpm migrate`。一次性迁移工具已退役；结构设计、读写契约和旧表删除结论见 [日线存储](日线存储.md)。新增结构不使用外键，引用语义由业务代码验证。

## 指数日线

刷新证券清单会维护主要指数目录，使用 `sh`/`sz` 加六位数字区分股票；例如沪深300为 `sh000300`。在侧栏“指数数据”或“数据管理 → 指数数据”可直接选择指数与日期区间补齐日线；通用数据拉取页也提供“同步指数数据”入口。盘后行情同步包含指数，股票财务等任务排除指数；证券清单差集不会将指数标成退市。指数无需数据库迁移，存入现有行情表且固定不复权。指数仅作研究和回测基准，不能交易；数据详情页标注此限制。

指数适配沿用 [AKShare 指数历史接口](https://github.com/akfamily/akshare/blob/main/akshare/index/index_zh_em.py) 与现有日线来源切换。来源失败不会补造行情；新目录本身不包含价格，须同步所需区间才能运行带基准的回测。

指数页面无需先刷新股票清单即可展示主要指数、已有区间、条数和未同步/落后/已更新状态；可单选或全选，默认选择沪深300。提交后显示后台任务、来源尝试及失败原因，任务结束自动刷新覆盖，已有数据可跳转 K 线。同步成功只表示采集完成，来源缺少区间数据时仍显示真实覆盖与提示；不得将任务成功等同于区间完整。

管理员接口 `GET /api/v1/admin/market-data/indices` 读取目录和覆盖，查询只聚合所列指数，不扫描股票日线；读取不写证券目录。`POST /api/v1/admin/market-data/indices/acquisitions` 校验指数和日期后复用 `daily-bars` 任务，非法代码或倒序日期返回 422，不入队。指数共享日线来源开关，页面可跳转“日线来源配置”，不建立重复的数据源配置。页面覆盖仅概括首末日期和条数，区间内缺日仍由基准回测的完整性检查阻止。
